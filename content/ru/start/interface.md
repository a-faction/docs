## Поиск { #search }

Открыть: ++ctrl+k++ (Mac: ++cmd+k++), клавиша ++slash++ вне поля ввода или поле в шапке.

Находит: разделы меню, разделы настроек (если есть доступ), людей текущего сервера, статьи справки, уведомления и действия — открыть ИИ, написать в поддержку, прочитать все уведомления, сменить тему, язык или плотность, начать экскурсию, выйти.

| Знак в начале | Ищет только |
|---|---|
| `/` | разделы |
| `@` | людей |
| `?` | справку |
| `!` | уведомления |
| `>` | действия |

++tab++ — переключить область, стрелки — выбор, ++enter++ — открыть, ++esc++ — закрыть.

На страницах со списками своё поле поиска. Запрос сохраняется в адресе — ссылкой можно поделиться.

## Уведомления { #notifications }

Колокольчик и страница «Уведомления» показывают одно и то же:

- действия над вами (выговор, одобренный отчёт и т. д.);
- ответы поддержки, решения по заявкам, напоминания автоматизаций;
- новая версия панели.

Вкладки: «Все», «Непрочитанные»; на странице ещё «Сообщения» и «Журнал». Прочитанным становится то, на что нажали, или всё — **«Прочитать всё»**. Открытие колокольчика ничего не отмечает. Отметки синхронизируются между устройствами.

## Экскурсия по сайту

Пошаговый тур: подсвечивает настоящую кнопку и объясняет её. Пропускает недоступные вам разделы.

Запуск: **«Начать знакомство с сайтом»** в окне поддержки или на главной нового сервера, через поиск или **Настройки сайта → Помощь → Знакомство с сайтом**. Управление: ++arrow-left++ ++arrow-right++, ++enter++, ++esc++.

## Если не работает { #troubleshooting }

| Что видите | Почему | Что сделать |
|---|---|---|
| «Доступ ограничен… ограничен настройками сайта» | Раздел скрыт для вашей должности | Попросите администрацию — [Права](../settings/access.md) |
| «Нет соединения» | Пропал интернет | Панель подключится сама, когда связь вернётся |
| «Сайт недоступен» | Сервер перезапускается или доступ режет провайдер | Подождите минуту. Не помогает — попробуйте VPN, проверьте [статус](../help/status.md) |
| «Технические работы» | Идут работы | Нажмите «Проверить снова» позже |
| Полоса «Обнаружен сбой в работе сервисов» | Сбой уже обнаружен | Ничего делать не нужно, мы чиним |
| «Закрыть без сохранения?» | В окне есть введённые данные | «Отменить» — вернуться к заполнению |
| Странные отказы после долгого перерыва | Устаревшая вкладка | Обновите страницу |
