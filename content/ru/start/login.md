# Вход и устройства

<p class="af-lead" markdown>Никаких паролей: в A-Faction вы входите своим Discord-аккаунтом. Один раз вошли — и панель запомнит вас надолго.</p>

!!! abstract "Коротко"
    - **Где:** [crm.a-faction.xyz](https://crm.a-faction.xyz) → **«Войти через Discord»**.
    - **Сколько живёт вход:** долго, входить каждый день не нужно.
    - **Все входы:** раздел «Сессии».

## Как войти

<div class="af-steps" markdown>

1. Откройте [crm.a-faction.xyz](https://crm.a-faction.xyz) и нажмите **«Войти через Discord»**.
2. В Discord нажмите **«Авторизовать»**.
3. Вы вернётесь в панель.

</div>

Войти может только тот, кто есть в составе хотя бы одного сервера. Нет своего сервера — нужна [регистрация](../work/members.md#register) или [подключение своего](connect-server.md).

!!! tip "Защитите Discord"
    Своей двухэтапной проверки у панели нет — её даёт Discord. Включите в Discord: **Настройки → Моя учётная запись → Двухфакторная аутентификация**.

## Сессии { #sessions }

Раздел **«Сессии»** — все устройства, где выполнен вход: устройство, адрес, время входа и последней активности.

- завершить одну сессию — кнопка у строки;
- **«Выйти»** — на этом устройстве;
- **«Выйти со всех»** — везде.

!!! warning "Заходили с чужого компьютера"
    Закрыть вкладку недостаточно — завершите сессию в «Сессиях».

## Несколько серверов

Переключатель серверов — в шапке. У каждого сервера свои данные, права и названия, поэтому панель после переключения может выглядеть иначе.

## Если не работает { #troubleshooting }

| Что видите | Почему | Что сделать |
|---|---|---|
| «Доступ запрещен. У вас нет доступа к этой системе» | Вашего Discord-аккаунта нет в составе ни одного сервера | Попросите руководство зарегистрировать вас |
| «Вас нет ни на одном сервере» | Вас сняли со всех серверов | Попросите руководство добавить вас обратно или [подключите свой сервер](connect-server.md) |
| «Вы отменили авторизацию в Discord» | В окне Discord нажали «Отмена» | Войдите снова и нажмите «Авторизовать» |
| «Сессия авторизации истекла» | Окно входа было открыто слишком долго | Нажмите «Войти через Discord» заново |
| «Не получен код авторизации от Discord» / «Не удалось получить токен» / «…профиля Discord» | Сбой связи с Discord | Попробуйте ещё раз через минуту. Проверьте [статус](../help/status.md) |
| «Сервер перегружен» | Временная перегрузка | Повторите через несколько секунд |
| «Внутренняя ошибка сервера» и код | Сбой на нашей стороне | Попробуйте позже. Не помогло — напишите в [поддержку](../help/support.md) и укажите код |
| «Аккаунт заблокирован» | Блокировка защиты или администрации | См. [Блокировка](../help/troubleshooting.md#blocked) |
| «Сервер заморожен» | Сервер приостановлен администрацией платформы | Напишите в [поддержку](../help/support.md) |
| «Этот сервер вам недоступен» / «Не удалось сменить сервер» | Вас сняли с этого сервера или нет связи | Обновите страницу |
| «Сессии не найдены» | Вход устарел | Обновите страницу или войдите заново |
| Постоянно выкидывает из панели | Браузер удаляет данные сайтов или блокирует сторонние данные | Разрешите сохранять данные для crm.a-faction.xyz, отключите очистку при закрытии |
