# Подключить сервер

<p class="af-lead">Подключение Discord-сервера к A-Faction. Бесплатно, около двух минут.</p>

!!! abstract "Коротко"
    - **Где:** [a-faction.xyz](https://a-faction.xyz) → «Подключить сервер». В панели такой кнопки нет.
    - **Что нужно:** Discord-аккаунт и права администратора на своём Discord-сервере.
    - **Ограничение:** один человек может владеть только одним сервером.

## Шаги

<div class="af-steps" markdown>

1. **Аккаунт и сервер.** Введите свой Discord ID или никнейм и ID Discord-сервера. Нажмите **«Получить код»**.
2. **Код из Discord.** Бот пришлёт в личные сообщения код из 6 цифр — введите его.
3. **Бот на сервере.** Нажмите **«Добавить бота»**, выберите свой сервер, подтвердите права, вернитесь и нажмите **«Проверить наличие бота»**.
4. **Данные сервера.** Название (подставится само), категория, ваш никнейм, имя, возраст (14–80), соцсети по желанию. Нажмите **«Зарегистрировать сервер»**.
5. **Вход.** Нажмите **«Открыть CRM»** и войдите через Discord — профиль владельца уже создан. **«Получить роли»** выдаст вам роли в Discord.

</div>

После этого панель пустая — это нормально. Дальше: [первая настройка](first-steps.md).

## Как узнать ID

Ник можно поменять, а ID — это постоянный номер из 17–20 цифр.

<div class="af-steps" markdown>

1. Discord → **Настройки пользователя → Расширенные** → включите **«Режим разработчика»**.
2. ID сервера: правой кнопкой по серверу в списке слева → **«Копировать ID сервера»**.
3. Свой ID: правой кнопкой по своему аватару → **«Копировать ID пользователя»**.

</div>

## Правила кода

- Действует **10 минут**, подходит **один раз**.
- Отправить можно до **3 раз**, ввести — до **10 раз** за 15 минут.

## Если не работает { #troubleshooting }

| Что видите | Почему | Что сделать |
|---|---|---|
| Код не приходит | Бот пишет только тем, с кем у него общий сервер, и только если открыты личные сообщения | Зайдите на [Discord-сервер A-Faction](https://discord.gg/2cMBp8gjYn), в Discord включите **Конфиденциальность → Личные сообщения от участников сервера**, нажмите **«Отправить ещё раз»** |
| «Код уже отправлялся несколько раз. Подождите 15 минут» | Превышен лимит отправок | Подождите 15 минут |
| «Код не найден. Запросите новый» / «Код уже был использован» | Код истёк (10 минут) или уже введён | Запросите новый код |
| Бот не находится на шаге 3 | Бота добавили на другой сервер или не подтвердили приглашение | Нажмите «Добавить бота» ещё раз и выберите именно тот сервер, ID которого ввели |
| «Этот сервер уже зарегистрирован» | Discord-сервер уже подключён | Если это ваш сервер — напишите в [поддержку](../help/support.md) |
| «Вы уже являетесь владельцем зарегистрированного сервера» | Владеть можно только одним сервером | Используйте существующий или напишите в поддержку |
| «Регистрация остановлена» | Сбой на одном из шагов | Повторите. Не помогло — [поддержка](../help/support.md) |
