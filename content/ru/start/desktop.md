# Приложение для компьютера

<p class="af-lead">Отдельное приложение для Windows и macOS. Те же разделы, что в браузере.</p>

!!! abstract "Коротко"
    - **Скачать:** [a-faction.xyz/desktop](https://a-faction.xyz/desktop) — сайт сам предложит нужную версию.
    - **Обновления:** приходят сами.
    - **Вход:** через Discord.

## Установка

<div class="af-steps" markdown>

1. Откройте [a-faction.xyz/desktop](https://a-faction.xyz/desktop) и скачайте версию для своей системы.
2. Запустите скачанный файл и следуйте установщику.
3. Откройте приложение и нажмите «Войти через Discord».

</div>

## Телефон

Отдельного приложения для телефона нет. Откройте [crm.a-faction.xyz](https://crm.a-faction.xyz) в браузере и выберите в меню браузера **«Добавить на главный экран»** — панель откроется как приложение.

## Если не работает { #troubleshooting }

| Что видите | Почему | Что сделать |
|---|---|---|
| Windows: «Система Windows защитила ваш компьютер» | Новое приложение ещё мало кто скачивал | Нажмите **«Подробнее» → «Выполнить в любом случае»** |
| macOS: «Не удаётся открыть приложение» | Защита macOS для приложений из интернета | Правой кнопкой по приложению → **«Открыть»** → **«Открыть»** |
| Приложение не обновляется | Нет связи с сервером обновлений | Перезапустите приложение. Не помогло — скачайте заново с сайта |
| Белый экран | Сбой загрузки | Перезапустите. Проверьте [статус](../help/status.md) |
