# Формы Discord

<p class="af-lead" markdown>Научите бота работать на вас: кнопки для заявок, автоответы, выпадающие меню и выдача ролей одной командой.</p>

!!! abstract "Коротко"
    - **Где:** боковое меню → «Формы Discord».
    - **Право:** «Формы» в группе «Дискорд» (Настройки команд и форм).

## Виды правил

| Вид | Что делает |
|---|---|
| **Форма** | Сообщение с кнопками. Участник подаёт заявку, бот присылает карточку с кнопками «Одобрить» / «Отказать» |
| **Команда** | Показывает список людей с ролью или выдаёт/снимает роль командами `/a_название`, `/d_название` |
| **Ответ** | Бот отвечает заготовленным текстом |
| **Селектор** | Сообщение с выпадающим меню, каждый пункт — свой ответ |

## Создать правило

<div class="af-steps" markdown>

1. «Формы Discord» → создать → выберите вид.
2. Название правила (уникальное на сервере).
3. Каналы и роли с доступом — из списка вашего Discord.
4. Оформление карточки: цвет, заголовок, поля, картинка.
5. Кнопки: ID, текст, цвет. «Просить причину» — бот попросит текст при нажатии. «Убирать кнопки после нажатия» — по желанию.
6. Что делать с сообщением участника: удалить или закрепить. Кого упомянуть.
7. Сохраните — бот опубликует правило.

</div>

В тексте можно использовать подстановки — список показан в окне правила.

## Таблица правил

Переключатель вкл/выкл (выключенное правило не реагирует), поиск, фильтры, массовое редактирование и удаление.

## Если не работает { #troubleshooting }

| Что видите | Почему | Что сделать |
|---|---|---|
| «Нельзя сохранить» + список полей | Не заполнены обязательные поля | Заполните перечисленные |
| «Кнопки (есть одинаковые ID)» | Повтор ID кнопки | Сделайте ID разными |
| «Правило сохранено, но не указан канал для публикации» | Нет канала | Выберите канал |
| «Правило сохранено, но выбранный канал не является текстовым» | Голосовой канал или категория | Выберите текстовый |
| «Правило сохранено, но канал не найден или у бота нет доступа» | Канал закрыт для бота | Откройте доступ боту |
| «Канал не принадлежит вашему серверу» | Канал из другого Discord | Выберите свой |
| «Роль не найдена на вашем сервере» | Роль удалена | Выберите заново |
| Название правила занято | Уже есть правило с таким именем на сервере | Переименуйте |
| Бот не выдаёт роль по команде | Роль бота ниже | [Поднимите роль бота](../start/connect-bot.md#troubleshooting) |
| Правило не реагирует | Выключено | Включите переключателем |
