# Команды бота

<p class="af-lead" markdown>Самые нужные действия — одной командой в чате. Наберите `/` в любом канале, где есть бот, и выберите нужную.</p>

| Команда | Что делает | Нужное право |
|---|---|---|
| `/user @участник` | Профиль: должность, коины, выговоры, соцсети, достижения, кнопка «История действий» | — |
| `/registration @участник` | Регистрация | «Регистрация» (участники или администрация) |
| `/reprimand @участник` | Выдать или снять выговор | На этот тип выговора |
| `/coins @участник` | Начислить или списать коины | «Коины» |
| `/shop @участник` | Списать коины за товар | «Коины» |
| `/demote @участник` | Снять с должности: роли и запись в составе | «Удаление» или «Снятие» (администрация) |
| `/archive @участник` | Архив должностей | — |
| `/log @участник [с] [по]` | Журнал за период | — |
| `/faction_bug текст` | Сообщить об ошибке | — |
| `/ping` | Проверить, отвечает ли бот | — |
| `/help` | Список команд | — |
| `/xo` | Крестики-нолики с ботом | — |

Плюс свои команды сервера из [Форм Discord](discord-forms.md): `/a_название` и `/d_название` (выдать и снять роль), списки ролей, автоответы.

## Правила

- Права те же, что в панели.
- [Старшинство](../settings/hierarchy.md) действует: над старшими — нельзя.
- В нескольких сообществах бот попросит выбрать сервер.
- Заблокированный аккаунт команды не выполняет.

## Если не работает { #troubleshooting }

| Ответ бота | Почему | Что сделать |
|---|---|---|
| «Вы не зарегистрированы» | Вас нет в составе | Пройдите регистрацию |
| «У вас нет прав на это действие» | Нет права | [Права](../settings/access.md) |
| «У вас нет права регистрировать игроков» / «…администрацию» | Нет права «Регистрация» | То же |
| «У вас нет права снимать игроков» / «…участников администрации» | Нет права «Удаление» / «Снятие» | То же |
| «У вас нет прав на этот тип санкции» | Нет права на тип выговора | То же |
| «Нельзя применять это действие к вышестоящему участнику» | Человек старше | См. [Старшинство](../settings/hierarchy.md) |
| «У вас нет доступа к серверу этого игрока» | Человек на другом сервере | — |
| «Игрок числится на нескольких серверах. Выберите…» | Нужно выбрать сервер | Выберите в меню |
| «Игрок не найден на этом сервере» | Человек не в составе | Проверьте упоминание |
| «Не удалось найти пользователя на Discord сервере» | Человека нет на Discord-сервере | Пригласите его |
| «Выбранная должность не найдена в списке» | Структура изменилась | Повторите команду |
| «Выбранный товар не найден» | Товар удалили | Повторите |
| «Ваш аккаунт заблокирован в A-Faction» | Блокировка | [Поддержка](../help/support.md) |
| «Не удалось определить сервер. Повторите команду» | Сбой выбора | Повторите |
| Команды нет в списке | Бот не на сервере или Discord ещё не обновил список | Подождите пару минут, перезапустите Discord |
| Бот молчит | Бот не работает | Проверьте `/ping` и [статус](../help/status.md) |
