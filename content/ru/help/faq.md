# Частые вопросы

<p class="af-lead" markdown>Короткие ответы на то, что спрашивают чаще всего. Нажмите на вопрос, чтобы раскрыть ответ.</p>

## Подключение

??? question "Как подключить сервер?"
    a-faction.xyz → «Подключить сервер», 4 шага, около 2 минут. [Подробно](../start/connect-server.md).

??? question "Не приходит код"
    Зайдите на [Discord A-Faction](https://discord.gg/2cMBp8gjYn), разрешите личные сообщения от участников серверов, отправьте код ещё раз.

??? question "Где взять ID сервера?"
    Discord → Настройки → Расширенные → «Режим разработчика». Правой кнопкой по серверу → «Копировать ID сервера».

??? question "Сколько стоит?"
    Бесплатно. Платный только [Premium](../account/premium.md) — оформление.

??? question "Можно владеть несколькими серверами?"
    Нет, один человек — один сервер. Состоять можно в нескольких.

??? question "Как перенести настройки с другого сервера?"
    Пресеты → Настройки → выгрузить и применить. [Подробно](../settings/presets.md).

??? question "Как передать, заморозить или удалить сервер?"
    Через [поддержку](support.md) — это делает администрация платформы.

## Вход и доступ

??? question "Почему не пускает?"
    Вас нет в составе, сервер не привязан или аккаунт заблокирован. [Подробно](../start/login.md#troubleshooting).

??? question "Пропал раздел"
    Его скрыли для вашей должности. [Права](../settings/access.md).

??? question "Раздел вижу, кнопки нет"
    Нет права на действие или человек старше вас.

??? question "Заблокировало после обычных действий"
    Обновите страницу и напишите в [поддержку](support.md) — снимут вручную.

??? question "Заходил с чужого компьютера"
    «Сессии» → завершите тот вход.

??? question "Есть двухэтапная проверка?"
    Своей нет — включите её в Discord.

## Discord

??? question "Бот не выдаёт роли"
    Роль бота должна быть выше выдаваемых. [Подробно](../start/connect-bot.md#troubleshooting).

??? question "Вместо названия роли — номер"
    Бот не видит роль или канал.

??? question "Действие прошло, в Discord пусто"
    Discord или бот были недоступны, либо не выбран канал. Данные не теряются.

## Работа

??? question "Цифры в профиле не сходятся"
    Проверьте вкладку сервера в профиле — данные по серверам отдельные.

??? question "Отчёт или неактив?"
    Отчёт — сделанная работа, за неё коины. Неактив — согласованное отсутствие.

??? question "Почему время другое?"
    Панель работает по UTC+3 для всех.

??? question "Можно исправить запись журнала?"
    Нет — журнал неизменяемый.

??? question "Как долго хранятся записи собеседований?"
    14 дней.
