# A-Faction AI

<p class="af-lead" markdown>Помощник, который знает панель наизусть и видит ваши права. Спросите — и он объяснит, где что лежит и почему вам что-то недоступно.</p>

## Чат-помощник

!!! abstract "Коротко"
    - **Где:** кнопка «A-Faction AI» в шапке.
    - **Видят:** те, кому разрешён пункт «A-Faction AI» в правах.

- Знает, как устроена панель, и **ваши** данные: должности, права, выговоры, действия над вами, архив, заявки.
- **Не видит** данных других людей и чужих серверов.
- Отвечает только про A-Faction, на языке вопроса.
- ++esc++ или крестик — закрыть, «+» — новый чат. Переписка сохраняется при переходах.
- Пауза между вопросами — 10 секунд.
- Нейросеть не ответила — придёт статья справки по теме.

## Разбор участника { #member-review }

!!! abstract "Коротко"
    - **Где:** иконка мозга в шапке [профиля](../work/profile.md).
    - **Кто:** право «Данные».

Четыре периода: неделя, месяц, весь срок, дисциплина. Под текстом — цифры, на которых он построен.

- Считается по открытой вкладке сервера.
- ИИ получает только цифры и ник.
- Открытие показывает последний разбор, **«Пересобрать»** — новый.

!!! warning "Подсказка, а не решение"
    Выводы делает языковая модель — перепроверяйте по цифрам.

## Если не работает { #troubleshooting }

| Сообщение | Причина | Решение |
|---|---|---|
| «Подождите N с» | Пауза между вопросами | Подождите |
| «ИИ пишет ответ — подождите» | Предыдущий ответ ещё пишется | Дождитесь |
| «ИИ упёрся в лимит запросов» | Лимит | Через минуту. Если не помогло — дневной лимит, обновится в 10:00–11:00 по UTC+3 |
| «Сообщение слишком длинное» | Больше лимита | Сократите |
| «Сообщение пустое» | Пустое поле | Напишите вопрос |
| «Не удалось получить разбор» | Сбой | Позже |
| Нет кнопки | Пункт скрыт правами | [Права](../settings/access.md) |
| Ответ неверный | Модель ошиблась | Проверьте по документации, напишите в [поддержку](support.md) |
