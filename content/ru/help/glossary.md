# Словарь

<p class="af-lead" markdown>Простыми словами — о словах, которые встречаются в панели и в этой документации.</p>

Панель (CRM)
:   Сайт [crm.a-faction.xyz](https://crm.a-faction.xyz), где команда ведёт работу.

Сервер
:   Ваше сообщество в A-Faction. Обычно = один Discord-сервер.

Discord ID
:   Постоянный номер аккаунта, сервера, роли или канала в Discord, 17–20 цифр. Ник меняется, ID — нет.

Режим разработчика
:   Настройка Discord, которая позволяет копировать ID: Настройки → Расширенные.

Бот
:   Программа на вашем Discord-сервере, выполняет команды от имени A-Faction.

Команда бота
:   Сообщение, начинающееся с `/`, например `/user`.

Подразделение
:   Фракция, отдел, организация. Название зависит от сервера.

Группа
:   Заголовок раздела в таблице участников. Объединяет несколько фракций. Раньше называлась «министерством».

Должность
:   Положение человека в подразделении. От неё зависят права и роль в Discord.

Старшинство
:   Кто кем может руководить. Задаётся порядком должностей.

Права
:   Что человек видит и может делать в панели.

Владелец сервера
:   Тот, кто подключил сервер. Может всё на своём сервере.

Администрация платформы
:   Команда A-Faction: поддержка, блокировки, передача и удаление серверов.

Выговор (взыскание)
:   Наказание: устный, строгий, министерский, предупреждение.

Эскалация
:   Автоматическое усиление выговоров при достижении лимита.

Иммунитет
:   Защита, которой можно снять выговор.

Неактив
:   Согласованное отсутствие.

Коины
:   Внутренняя валюта. Может называться иначе.

Обзвон
:   Собеседование кандидатов.

Слот
:   Отрезок времени в планировщике.

Журнал (логи)
:   Неизменяемый список всех действий.

Архив
:   Люди, снятые с должности, с историей.

Сессия
:   Вход с конкретного устройства.

Вебхук
:   Сообщение в Discord от имени бота.

Карточка
:   Оформленное сообщение Discord: цветная полоса, заголовок, поля.

Форум
:   Тип канала Discord, где каждое обсуждение — отдельная тема.

Ветка
:   Отдельное обсуждение внутри канала или форума Discord.

Пресет
:   Готовый набор настроек или названий.

Автоматизация
:   Правило «если — то», срабатывает само.

UTC+3
:   Часовой пояс, по которому работает панель.

Premium
:   Платное оформление профиля.
