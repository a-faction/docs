# Все ошибки и решения

<p class="af-lead" markdown>Увидели непонятное сообщение? Найдите его здесь — рядом будет простое объяснение и что сделать. Быстрее всего — ++ctrl+f++.</p>

## Сначала попробуйте

<div class="af-steps" markdown>

1. **Обновите страницу.** Вкладка, долго висевшая открытой, — частая причина странных отказов.
2. **Проверьте [статус](status.md).** Если там сбой — мы уже чиним.
3. **Проверьте сервер** в шапке: нужный ли открыт.
4. **Спросите [A-Faction AI](ai.md)** — он видит ваши права.
5. **Напишите в [поддержку](support.md).**

</div>

## Вход

| Сообщение | Решение |
|---|---|
| «Доступ запрещен» / «У вас нет доступа к этой системе» | Вас нет в составе — попросите руководство зарегистрировать вас |
| «Вас нет ни на одном сервере» | Попросите вернуть вас или [подключите свой сервер](../start/connect-server.md) |
| «Вы отменили авторизацию в Discord» | Войдите снова и нажмите «Авторизовать» |
| «Сессия авторизации истекла» | Нажмите «Войти через Discord» заново |
| «Сервер перегружен» | Повторите через несколько секунд |
| «Внутренняя ошибка сервера» + код | Попробуйте позже, сообщите код в поддержку |
| Постоянно выкидывает | Разрешите браузеру сохранять данные crm.a-faction.xyz |

Подробно — [Вход и устройства](../start/login.md#troubleshooting).

## Блокировка { #blocked }

| Сообщение | Что значит | Решение |
|---|---|---|
| «Аккаунт заблокирован» + «подозрительные операции… автоматически заблокирован» | Сработала защита. Часто ложно — из-за старой вкладки | Обновите страницу и напишите в [поддержку](support.md). Снимают вручную |
| «Для вашего профиля включена блокировка доступа» | Блокировка администрацией платформы | [Поддержка](support.md) |
| «Сервер заморожен» | Сервер приостановлен | [Поддержка](support.md) |

## Доступ и права

| Сообщение | Решение |
|---|---|
| «Доступ ограничен… ограничен настройками сайта» | Раздел скрыт для вашей должности — [Права](../settings/access.md) |
| «Недостаточно прав для этого действия» | Нет права на действие — [Права](../settings/access.md) |
| «Должность стоит выше вашей — действие недоступно» | Человек старше — [Старшинство](../settings/hierarchy.md) |
| «Нельзя выдать роль выше собственной» | Назначать выше себя нельзя |
| «Это действие нельзя применить к себе» | Попросите другого руководителя |
| «Это действие недоступно» / «Этот раздел недоступен» | Раздел выключен на сервере |
| «Эти отметки менять себе нельзя» | Достижения и Premium выдаёт только администрация платформы |
| «Менять должности этим действием нельзя» | Используйте «Сменить подразделение/должность» в профиле |
| «Запись относится к другому серверу» / «…к другой организации» | Переключите сервер, обновите страницу |
| «Сервер не выбран» | Выберите сервер в шапке или обновите страницу |
| «У вас нет доступа ни к одному серверу» | Попросите руководство зарегистрировать вас |
| «Не удалось проверить права. Попробуйте через минуту» | Временный сбой — подождите |

## Сохранение

| Сообщение | Решение |
|---|---|
| «Не удалось выполнить действие» / «Ошибка на сервере» | Повторите. Повторяется — поддержка |
| «Такая запись уже есть» | Дубль — используйте существующую |
| «Слишком много изменений за один раз» | Разбейте на части |
| «Это поле менять нельзя» / «Запрос собран неверно» / «Запрос содержит неизвестное поле» | Обновите страницу — у вас старая версия панели |
| «Осторожно — есть несохранённые изменения!» | Нажмите «Сохранить изменения» |

## Discord

| Сообщение | Решение |
|---|---|
| «Действие выполнено, но уведомление не отправилось: канал не найден или у бота нет доступа» | Откройте боту канал в Discord |
| «…выбранный канал не является текстовым» | Выберите текстовый канал |
| «…указан неверный канал» | Выберите канал заново |
| «Не удалось отправить уведомление в ЛС» | У человека закрыты личные сообщения — действие выполнено |
| «Не удалось выдать роли Discord» / «Роль … стоит выше роли бота» | [Поднимите роль бота](../start/connect-bot.md#troubleshooting) |
| «Роль … управляется интеграцией» | Привяжите к должности обычную роль |
| Вместо названия — длинный номер | Бот не видит роль или канал |
| «Бота нет на этом Discord-сервере» | [Добавьте бота](../start/connect-bot.md) |
| Ответы бота на команды | [Команды бота](../discord/commands.md#troubleshooting) |

## Связь и сбои

| Сообщение | Решение |
|---|---|
| «Нет соединения» | Проверьте интернет — панель подключится сама |
| «Сайт недоступен» | Подождите минуту. Не помогает — VPN, [статус](status.md) |
| «Технические работы» | Нажмите «Проверить снова» позже |
| Полоса «Обнаружен сбой в работе сервисов» | Ничего делать не нужно, чиним |
| Белый экран | Обновите страницу (++ctrl+shift+r++), очистите кэш, попробуйте другой браузер |

## Время

Панель работает по **UTC+3** — одинаково для всех. Если время в планировщике или журнале отличается от вашего, это разница часовых поясов.
