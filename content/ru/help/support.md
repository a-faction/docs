# Поддержка

<p class="af-lead" markdown>Живые люди, которые помогут, если ничего не помогло. Ответ придёт прямо в панель и в личные сообщения Discord.</p>

!!! abstract "Коротко"
    - **Где:** кнопка «Поддержка» в подвале панели.
    - **Одно открытое обращение** за раз.
    - **Ответ:** в окне поддержки, в колокольчике и в личных сообщениях Discord.

<div class="af-steps" markdown>

1. «Поддержка» в подвале.
2. Выберите тему — начало текста подставится — или пишите сразу.
3. Опишите: что делали, что ожидали, что увидели. Приложите скриншот.
4. Отправьте.

</div>

Ник, сервер и должность передаются сами.

| Статус | Значение |
|---|---|
| Открыто | Ждёт ответа |
| В работе | Разбираемся |
| Закрыто | Решено. Чтобы ответить — откройте снова |

Новый ответ при закрытом окне: всплывающее сообщение и счётчик у кнопки.

## Другие способы

- **A-Faction AI** — кнопка в окне поддержки.
- `/faction_bug текст` в Discord.
- [Discord-сервер A-Faction](https://discord.gg/2cMBp8gjYn).

## Если не работает { #troubleshooting }

| Сообщение | Решение |
|---|---|
| «У вас уже есть активное обращение» | Пишите в него |
| «Обращение закрыто. Чтобы написать ответ, сначала откройте его» | Откройте обращение |
| «Сообщение длиннее N символов» | Сократите или разбейте |
| «Сессия истекла. Войдите в аккаунт заново» | Войдите снова |
| «Не удалось отправить сообщение» | Повторите. Нет связи — напишите в Discord-сервер |
