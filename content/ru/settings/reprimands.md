# Настройка выговоров

<p class="af-lead" markdown>Настройте дисциплину под свои правила: какие бывают выговоры, сколько их можно получить и во что они превращаются, когда лимит исчерпан.</p>

!!! abstract "Коротко"
    - **Где:** Настройки сайта → Выговоры.
    - **Вкладки:** «Типы» и «Синхронизация».

## Типы

| Настройка | Что задаёт |
|---|---|
| Название | Как тип называется у вас |
| Лимит | Максимум выговоров этого типа у одного человека. «Без лимита» — снять ограничение |
| Кто выдаёт | Через права «Строгие», «Устные», «Министерские» |
| Эскалация | При достижении лимита выговоры превращаются в другой тип. Например, 3 устных → 1 строгий |
| Снимается иммунитетом | Можно ли снять этот тип иммунитетом |

## Синхронизация с Discord { #sync }

<div class="af-steps" markdown>

1. Выберите **форумный канал** и метку.
2. Впишите **название темы** и **правила**.
3. Выберите **роли проверяющих**.
4. **«Опубликовать тему»** — бот создаст тему с кнопкой «Подать заявление».
5. После правок — **«Обновить тему»**. Переключатель включает и выключает приём.

</div>

Как работают заявления — [Снятие выговоров](../work/appeals.md).

## Если не работает { #troubleshooting }

| Сообщение | Причина | Решение |
|---|---|---|
| «Заполните форум, название темы и текст правил» | Пустые поля | Заполните |
| «Форум не найден или у бота нет к нему доступа» | Закрыт для бота | Откройте боту доступ |
| «Выбранный канал не является форумом» | Обычный канал | Создайте в Discord канал типа «Форум» |
| «Нужно право на настройки сервера» | Нет права | «Доступ к настройкам» |
| «Тема создана заново в новом форуме. Старую уберите вручную» | Сменили форум | Удалите старую тему в Discord |
| «Синхронизация отключена. Тему в Discord закрыть не удалось» | Нет доступа бота | Закройте тему вручную |
| «Не удалось синхронизировать выговоры с Discord» | Сбой | Повторите |
