# Пресеты и названия

<p class="af-lead" markdown>Ваши слова и готовые наборы: превратите «фракции» в «отделы», а настройки одного сервера перенесите на другой в пару кликов.</p>

!!! abstract "Коротко"
    - **Где:** Настройки сайта → Пресеты.

## Термины

Меняют только подписи во всей панели: «фракция» → «отдел», «коины» → «баллы». Единственное и множественное число задаются отдельно.

Готовые наборы: игровая фракция, гильдия, киберспортивная команда, команда модерации, волонтёрская команда. Любое слово — вручную. Данные и права не меняются.

## Настройки

Целый набор: структура, права, выговоры, планировщик и другие разделы.

- **Выгрузить** настройки своего сервера файлом.
- **Применить** готовый набор или файл. Точки покажут изменённые разделы. Ничего не записано, пока не нажмёте «Сохранить».

!!! info "Никогда не переносится"
    Привязка к Discord, каналы, вебхуки и секреты.

## Если не работает { #troubleshooting }

| Сообщение | Причина | Решение |
|---|---|---|
| «Файл не похож на шаблон настроек» | Не тот файл | Выберите файл, выгруженный из A-Faction |
| «Версия шаблона … поддерживается …» | Старый формат | Выгрузите заново |
| «В шаблоне нет ни одной переносимой настройки» | Пустой файл | Выгрузите заново |
| После применения каналы пустые | Каналы не переносятся | Выберите каналы вручную |
