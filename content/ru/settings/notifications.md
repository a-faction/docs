# Уведомления и автоматизации

<p class="af-lead" markdown>Пусть система напоминает сама — о конце отпуска, о зависшем отчёте, о пропавшем участнике. А каждое событие уходит в нужный канал Discord.</p>

!!! abstract "Коротко"
    - **Где:** Настройки сайта → Уведомления. Автоматизации — там же, под каналами.
    - **Проверка правил:** каждые 10 минут.

## Каналы

Канал Discord на каждую тему: отпуска, выговоры, отчёты, коины, чёрный список, активность.

- Канал подразделения из [Структуры](structure.md) **важнее** общего.
- Темы без канала в Discord не пишут, но уведомление остаётся в колокольчике.

## Автоматизации { #automations }

Правила «если — то» без участия людей.

### События

| Событие | Порог |
|---|---|
| Заканчивается неактив | За N дней |
| Начинается неактив | — |
| Заканчивается чёрный список | За N дней |
| Отчёт без решения | N часов |
| Нет записей в журнале | N дней |
| Не сдаёт отчёты | N дней |
| Заявление на снятие выговора без решения | N дней |
| Заявка на коины без решения | N дней |

### Действия

- **Уведомить участника** или **руководство** — людей или должность (состав подставится в момент отправки).
- **Дублировать в личные сообщения** Discord.
- **Отправить в канал** — канал по теме события (канал подразделения важнее).
- Подстановки: `{ник}`, `{дата}`, `{правило}`. Ссылка — только внутренняя, начинается с `/`.

### Создать

<div class="af-steps" markdown>

1. **«+ Правило»** или заготовка («Напомнить о конце неактива» — за 3 дня).
2. Название, событие, порог.
3. **«+ Действие»**: кому, заголовок, текст, ЛС, канал.
4. Сохраните.

</div>

Одно правило срабатывает на одну запись **один раз**.

## Если не работает { #troubleshooting }

| Сообщение / ситуация | Причина | Решение |
|---|---|---|
| «Не задано название правила» | Пусто | Заполните |
| «Не выбрано событие» | Пусто | Выберите |
| «Нужно хотя бы одно действие» | Нет действий | «+ Действие» |
| «Действие N: не выбран ни один получатель» | Пусто «Кому» | Выберите человека или должность |
| «Действие N: пустой заголовок уведомления» | Пусто | Заполните |
| «Действие N: ссылка должна быть внутренней и начинаться с „/“» | Внешняя ссылка | Например, `/inactive` |
| Правило не сработало | Ещё не прошло 10 минут или уже срабатывало на эту запись | Подождите. Повторно на ту же запись не сработает |
| В Discord не пришло, в колокольчике есть | Для темы не выбран канал | Выберите канал |
| В ЛС не пришло | У человека закрыты личные сообщения | Колокольчик получит в любом случае |
| У правила «ошибка: …» | Последний запуск упал | Проверьте каналы и получателей |
