# Права и доступ

<p class="af-lead" markdown>Каждый видит только то, что ему нужно: рядовым — простое меню, руководству — нужные кнопки. Всё настраивается галочками.</p>

!!! abstract "Коротко"
    - **Где:** Настройки сайта → Права.
    - **Три уровня:** полный доступ → видимость разделов → права на действия.

## 1. Полный доступ

Владелец сервера и администрация платформы видят и могут всё.

## 2. Видимость разделов

Для каждого пункта меню: включён или скрыт, каким должностям и подразделениям виден, своё название.

**Пустой список = видно всем.** «Настройки сайта» выключить нельзя, но можно ограничить.

## 3. Права на действия

Отметьте галочкой действие для должности — у неё появится кнопка.

| Группа | Право | Что разрешает |
|---|---|---|
| Руководство | Строгие | Выдавать и снимать строгие выговоры |
| | Устные | Выдавать и снимать устные |
| | Министерские | Выдавать и снимать министерские |
| | Иммунитет | Выдавать и снимать иммунитет |
| | Коины | Начислять и списывать коины |
| | Регистрация | Добавлять участников |
| | Удаление | Снимать участников |
| | Данные | Править ник, контакты |
| | Фракция/должность | Менять подразделение и должность |
| | Срок | Менять срок должности |
| | ЧС: выдача | Подавать в чёрный список |
| | ЧС: решение | Одобрять и отклонять чёрный список |
| | Отчёты | Одобрять и отклонять отчёты |
| Администрация | Регистрация | Добавлять руководство |
| | Снятие | Снимать руководство |
| | Должность админа | Менять должность руководству |
| Дискорд | Формы | Настраивать [Формы Discord](../discord/discord-forms.md) |
| | Вебхуки | [Отправлять сообщения от бота](../discord/webhooks.md) |
| Собеседование | Собеседование | Доступ к обзвонам и результатам |
| | Удаление обзвонов | Удалять обзвоны |
| Настройки сервера | Доступ к настройкам | Открывать и менять настройки |
| Документы | Создание / Изменение / Удаление | Работа с [документами](../work/documents.md) |
| Формы | Формы | Создавать [формы](../work/forms.md) и читать ответы |

Те же права проверяет бот.

**Аудит прав** — в профиле человека можно посмотреть, что именно ему разрешено.

## Если не работает { #troubleshooting }

| Ситуация | Причина | Решение |
|---|---|---|
| Пропал раздел меню | Видимость: в списке нет вашей должности | Добавьте должность в видимость пункта |
| «Доступ к этой странице ограничен настройками сайта» | То же | То же |
| Раздел виден, кнопки нет | Нет права на действие | Отметьте право для должности |
| «Недостаточно прав для этого действия» | То же | То же |
| Кнопка есть, но «Должность стоит выше вашей» | Человек старше | См. [Старшинство](hierarchy.md) |
| «Нельзя выдать роль выше собственной» | Попытка назначить выше себя | Назначает кто-то старше |
| Права пропали после переименования должности | Не согласились на перенос | См. [Структура](structure.md#troubleshooting) |
| Права изменили, а у человека по-старому | Права обновляются в течение ~10 секунд | Человеку — обновить страницу |

Не знаете, почему недоступно? Спросите [A-Faction AI](../help/ai.md) — он видит ваши права.
