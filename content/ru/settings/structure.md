# Структура

<p class="af-lead" markdown>Фундамент вашего сервера: отделы, должности и роли в Discord. С неё всё начинается — без структуры некого регистрировать.</p>

!!! abstract "Коротко"
    - **Где:** Настройки сайта → Структура.
    - **Две ветки:** администрация и обычные участники.

## Что настраивается

| Что | Зачем |
|---|---|
| **Министерства / группы** | Объединяют подразделения |
| **Организации / подразделения** | Фракции, отделы. Названия — из [терминов](presets.md) |
| **Типы должностей** | Лидер, заместитель, старший состав и т. д. |
| **Должности** | Название, срок, **роль Discord** — бот выдаст её при регистрации |
| **Канал уведомлений организации** | Сообщения о её людях уходят туда, а не в общий канал |
| **Причины регистрации** | Список причин в анкете регистрации |

## Порядок = старшинство

Кто выше в списке — тот старше. Порядок меняется перетаскиванием. См. [Старшинство](hierarchy.md).

## Переименование

При сохранении панель спросит: **«У N участников осталось прежнее название. Перенести?»** — соглашайтесь. Иначе люди потеряют права, потому что права выдаются по названиям. Работает и для должностей, и для подразделений.

## Если не работает { #troubleshooting }

| Что видите | Почему | Что сделать |
|---|---|---|
| «Такой тип должности уже существует» / «Такая причина уже существует» | Дубль | Используйте существующий |
| Нельзя удалить должность | В ней есть люди | Переведите или снимите их |
| «Не удалось перенести участников» | Сбой при переименовании | Повторите сохранение |
| Роль не выдаётся при регистрации | Роль не привязана или бот ниже | Привяжите роль, [поднимите роль бота](../start/connect-bot.md#troubleshooting) |
| Люди потеряли доступ после переименования | Отказались от переноса | Верните старое название или переназначьте людей |
