# Настройка словами

<p class="af-lead" markdown>Просто напишите, что поменять, — «добавь отдел», «переименуй должность», — а ИИ подготовит изменения и покажет их до сохранения.</p>

!!! abstract "Коротко"
    - **Где:** Настройки сайта → Помощь → ИИ-помощник.
    - **Кто:** право «Доступ к настройкам».

## Примеры

- «Добавь организацию ФБР в Госструктуры»
- «Переименуй должность Заместитель в Зам. лидера»
- «Включи планировщик»
- «Поставь Куратора выше Лидера»
- «Добавь причину регистрации»

## Как работает

<div class="af-steps" markdown>

1. Напишите, что изменить. Неясно — ИИ переспросит.
2. ИИ покажет план — каждое изменение строкой с галочкой.
3. **«Добавить в черновик»** — изменения появятся в настройках, но не сохранятся.
4. **«Сохранить»** внизу. **«Отменить»** — вернуть.

</div>

| Умеет | Не умеет |
|---|---|
| Добавлять и переименовывать подразделения, группы, должности, причины | Права на действия |
| Менять порядок (старшинство) | Роли и каналы Discord |
| Включать разделы | Сроки, лимиты выговоров |
| Менять названия (термины) | Время планировщика, колонки, автоматизации |

При переименовании люди, права, каналы и меню переезжают сами. Удалить подразделение с людьми нельзя.

## Если не работает { #troubleshooting }

| Сообщение | Причина | Решение |
|---|---|---|
| «ИИ не ответил» | Временный сбой | Повторите или измените вручную |
| «Организация … уже есть» / «Должность … уже есть» | Дубль | — |
| «… нет в настройках» | Опечатка в названии | Напишите название как в настройках |
| «… не в группе … — переставить можно только внутри группы» | Разные группы | Переставляйте внутри одной группы |
| «Не удалось посчитать участников — применить план нельзя» | Сбой | Повторите |
| «Права новой организации не выдаются» | ИИ не меняет права | Назначьте в [Правах](access.md) |
| «Сообщение длиннее N символов» | Слишком длинно | Сократите |
