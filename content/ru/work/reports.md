# Отчётность

<p class="af-lead">Отчёты о сделанной работе за период. За одобренный отчёт начисляются коины.</p>

!!! abstract "Коротко"
    - **Где:** боковое меню → «Отчётность».
    - **Подать:** любой участник с должностью.
    - **Проверять:** право «Отчёты».
    - **Править свой:** пока не проверен.

## Подать

<div class="af-steps" markdown>

1. «Отчётность» → **«Подать заявление»**.
2. Выберите подразделение и период.
3. Напишите текст. Кнопки над полем: заголовок, жирный, курсив, зачёркнутый, списки, задачи, цитата, код, ссылка, разделитель. Клавиши: ++ctrl+b++, ++ctrl+i++, ++ctrl+k++.
4. Вкладка **«Предпросмотр»** — так отчёт увидит проверяющий.
5. Отправьте. Статус — **«Ожидает»**.

</div>

Максимум — 20 000 символов.

## Исправить

**«Изменить»** в строке отчёта или в окне просмотра. Меняются период и текст. После решения правка закрыта.

## Проверить

- **Одобрить** + количество коинов — начислится каждому выбранному участнику.
- **Отклонить** — без начисления.

Решение — в журнале и в уведомлениях автора.

Напоминания: «отчёт без решения N часов», «участник не сдаёт отчёты N дней» — [автоматизации](../settings/notifications.md#automations).

## Если не работает { #troubleshooting }

| Что видите | Почему | Что сделать |
|---|---|---|
| «Отчёт пустой — напишите хотя бы один пункт» | Пустой текст | Заполните |
| «Отчёт слишком длинный — до 20 000 символов» | Превышен объём | Сократите |
| «Дата начала не может быть позже даты окончания» | Перепутаны даты | Исправьте |
| «Укажите настоящую дату — год из четырёх цифр» | Неверная дата | Исправьте |
| «Отчёт уже проверили — изменить его нельзя» | Решение принято | Подайте новый отчёт |
| «Изменять можно только свой отчёт» | Чужой отчёт | — |
| «… не найден в базе — возможно, снят с должности» | Автора сняли | Отклоните отчёт |
| «Должность … у игрока больше не числится» / «нет должностей на сервере — начислять некуда» | Должность изменилась | Отклоните или начислите коины вручную |
| Нет кнопок «Одобрить» / «Отклонить» | Нет права «Отчёты» | [Права](../settings/access.md) |
