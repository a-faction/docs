# Снятие выговоров

<p class="af-lead" markdown>Оступился — можно исправиться. Человек просит снять выговор, получает задание, выполняет его и приносит доказательства. Всё прозрачно — и на сайте, и в Discord.</p>

!!! abstract "Коротко"
    - **Где:** боковое меню → «Выговоры».
    - **Подать:** любой участник с выговором.
    - **Проверять:** право на выговоры, владелец, администрация платформы или роль из настроек синхронизации.
    - **Одно открытое заявление** на один тип выговора.

## Как идёт заявление

```
Ожидание  →  Выдано задание  →  На проверке  →  Одобрено / Отказано
```

## Подать

<div class="af-steps" markdown>

1. «Выговоры» → **«Новый запрос»** → выберите тип выговора.
2. Дождитесь задания. Оно придёт в уведомления и в личные сообщения Discord со ссылкой.
3. Выполните задание и нажмите **«Подать доказательства»**: ссылки, скриншоты, описание.
4. Дождитесь решения.

</div>

## Проверить

- **Выдать задание** — заявлениям в статусе «Ожидание».
- **Одобрить** — только после доказательств (статус «На проверке»). У человека станет на один выговор меньше, в журнале запись, в канал подразделения — объявление.
- **Отказать** — в любом незакрытом заявлении, даже без доказательств. После отказа можно подать новое.
- Несколько заявлений можно выделить и решить разом.

## Заявления в Discord { #discord }

Если включена синхронизация ([Настройки → Выговоры → Синхронизация](../settings/reprimands.md#sync)):

- на форуме висит тема с правилами и кнопкой **«Подать заявление»**;
- на каждое заявление бот создаёт ветку с кнопками **«Выдать задание»**, **«Подать доказательства»**, **«Одобрить»**, **«Отказать»**;
- всё, что сделано на сайте, повторяется в ветке, и наоборот.

## Если не работает { #troubleshooting }

| Что видите | Почему | Что сделать |
|---|---|---|
| «На текущем сервере у вас нет активной фракции для подачи заявления» | У вас нет должности на этом сервере | Переключите сервер или обратитесь к руководству |
| «На выбранной фракции нет доступных выговоров для снятия» | Снимать нечего | — |
| Кнопка «Новый запрос» не даёт выбрать тип | Уже есть открытое заявление на этот тип | Дождитесь решения |
| Нет кнопки «Подать доказательства» | Задание ещё не выдано или вы не автор | Дождитесь задания |
| «Выберите заявления со статусом „На проверке“» | Одобрять можно только после доказательств | Выдайте задание и дождитесь доказательств |
| «Не удалось одобрить заявление. Проверьте, что игрок существует…» | Человека сняли или у него уже нет этого выговора | Откажите в заявлении |
| «У игрока уже нет этого выговора» | Выговор сняли иначе | Откажите в заявлении |
| «Задание выдано, но уведомление в ЛС не доставлено» | У человека закрыты личные сообщения | Задание видно на сайте, сообщите человеку сами |
| «Действие выполнено, но ветка в Discord не обновилась» | Бот не может писать в форум | Проверьте доступ бота к форуму |
| «Решение применено, но уведомление в Discord не отправлено» | Нет канала подразделения или доступа | Проверьте [каналы](../settings/notifications.md) |
| Кнопки в теме Discord не работают | Тему опубликовали в другом форуме заново | Удалите старую тему вручную |
