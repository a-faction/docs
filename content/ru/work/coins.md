# Коины

<p class="af-lead">Внутренняя валюта сообщества. Могут называться иначе, например «баллы».</p>

!!! abstract "Коротко"
    - **Попросить:** «Запросить коины».
    - **Потратить:** «Потратить коины».
    - **Начислять и одобрять:** право «Коины» (Начислить/списать).
    - **Discord:** `/coins @участник`, `/shop @участник`.

## Откуда берутся

- одобренный запрос на начисление;
- одобренный [отчёт](reports.md);
- ручное начисление руководителем в [профиле](profile.md#actions) или `/coins`.

## Запросить

<div class="af-steps" markdown>

1. «Запросить коины».
2. Один запрос: ник, количество, причина. Или списком — по строке на человека: `Ник Количество Причина`.
3. Отправьте. Решает руководитель с правом.

</div>

## Потратить { #spend }

<div class="af-steps" markdown>

1. «Потратить коины» → выберите товар и количество.
2. Отправьте заявку на покупку.
3. Руководитель одобряет — коины списываются.

</div>

Товары и цены ведёт руководство с правом.

## Правила

- Баланс — отдельно по каждому серверу и подразделению.
- Бывают дробные значения, счёт точный.
- Каждое движение — в журнале: кто попросил, кто одобрил, сколько, баланс до и после.
- Отклонённый запрос баланс не меняет.
- Заявки можно решать пачкой. Решить можно, даже если автора уже сняли.
- Себе начислить нельзя — только тем, кто [младше](../settings/hierarchy.md).

## Если не работает { #troubleshooting }

| Что видите | Почему | Что сделать |
|---|---|---|
| «Недостаточно коинов во фракции … У вас N, нужно M» | Мало коинов | Накопите или выберите дешевле |
| «У вас нет фракций на этом сервере» | Нет должности | Переключите сервер |
| «Игрок не найден» | Ник с ошибкой или человека сняли | Проверьте ник |
| «Найдены ошибки: N» | В списке строк есть ошибки | Исправьте подсвеченные строки |
| «Товар не найден» | Товар удалили | Обновите страницу |
| Нет кнопки «Одобрить» | Нет права «Коины» | [Права](../settings/access.md) |
| «Это действие нельзя применить к себе» | Себе нельзя | Попросите другого руководителя |
