# Участники и регистрация

<p class="af-lead" markdown>Весь состав — в одной таблице. Найти человека, отфильтровать по отделу или зарегистрировать новичка — пара кликов, а роли в Discord бот выдаст сам.</p>

!!! abstract "Коротко"
    - **Где:** боковое меню → «Пользователи».
    - **Регистрировать:** нужно право «Регистрация» (участников) или «Регистрация» в группе «Администрация» (руководства).
    - **Из Discord:** `/registration @участник`.

## Таблица

- **Фильтры + поиск.** Сначала применяются фильтры, потом поиск ищет среди отфильтрованных. Включённые фильтры видны под поиском, снимаются одним нажатием.
- **Профиль** открывается нажатием на ник — в любом месте панели.
- **Колонки** одинаковые для всех руководителей сервера. Меняет администрация: [Таблица участников](../settings/table.md).
- **Телефон:** таблица превращается в карточки.
- **Неактив** у человека виден прямо в строке.

## Регистрация { #register }

### В панели

<div class="af-steps" markdown>

1. «Пользователи» → **«Создать»**.
2. Введите Discord ID человека. Панель проверит, что он есть на вашем Discord-сервере, и сверит его с [чёрным списком](blacklist.md).
3. Выберите подразделение, должность и срок.
4. Заполните ник, имя, возраст, соцсети (ВКонтакте и Telegram — отдельные необязательные поля).
5. Нажмите сохранить и дождитесь окончания шагов.

</div>

Дальше автоматически: выдача ролей в Discord, запись в журнал, приветствие человеку в личные сообщения. Ход видно по шагам в окне.

### Через Discord

`/registration @участник` → бот спросит подразделение, должность и данные. Права те же, что в панели.

### Ограничения

- Нельзя выдать должность выше своей или равную — в списке её не будет. См. [Старшинство](../settings/hierarchy.md).
- Заблокированный аккаунт зарегистрировать нельзя.
- Если человек уже есть на этом сервере, панель скажет: «Игрок уже зарегистрирован на этом сервере как …». Новую должность добавляют через [изменение данных](profile.md#actions).

## Несколько сообществ

Один Discord-аккаунт может состоять в нескольких серверах. У каждого сервера свои должности, ник и история.

## Когда человек уходит

Его не удаляют, а [снимают с должности](profile.md#actions) — он переходит в [архив](archive-logs.md) со всей историей.

## Если не работает { #troubleshooting }

| Что видите | Почему | Что сделать |
|---|---|---|
| Список пустой | Включены фильтры или ещё никого не добавили | Снимите фильтры под поиском. Проверьте, что настроены [структура](../settings/structure.md) и должности |
| «Под текущие фильтры и поиск не подходит ни одна запись» | Слишком узкие фильтры | Снимите фильтры |
| Нет кнопки «Создать» | Нет права на регистрацию | Попросите администрацию — [Права](../settings/access.md) |
| «Discord ID не найден на Discord сервере» | Человека нет на вашем Discord-сервере или ID с ошибкой | Пригласите человека на сервер, скопируйте ID заново |
| «Этот аккаунт заблокирован на A-Faction» | Аккаунт заблокирован администрацией платформы | Регистрация невозможна |
| Регистрация остановлена из-за чёрного списка | Человек в [чёрном списке](blacklist.md) | Проверьте запись. Если ошибка — исправьте или снимите её |
| «Не удалось проверить чёрный список» | Временный сбой | Повторите |
| «Недостаточно прав для регистрации администрации» | Нет права на регистрацию руководства | Нужно право «Регистрация» в группе «Администрация» |
| «Не удалось выдать роли Discord — продолжаем без них» | Роль бота ниже выдаваемой | Регистрация сохранена. [Поднимите роль бота](../start/connect-bot.md#troubleshooting), выдайте роли вручную |
| «Роли не выданы: человека нет на Discord-сервере» | Человек не зашёл в Discord | Пригласите и выдайте роли вручную |
| «Личное сообщение не отправлено, но регистрация сохранена» | У человека закрыты личные сообщения | Ничего делать не нужно |
| «Не удалось загрузить аватар» | Сбой загрузки картинки | Регистрация не страдает, аватар можно поставить позже |
| «Фракции не настроены» | Нет подразделений | Настройте [структуру](../settings/structure.md) |
| Нет нужной должности в списке | Она выше вашей или её нет в структуре | См. [Старшинство](../settings/hierarchy.md) |
