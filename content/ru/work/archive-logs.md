# Архив и журнал

<p class="af-lead" markdown>Ничего не теряется: ушедшие уходят в архив вместе с историей, а журнал навсегда помнит, кто, кому и что сделал.</p>

## Архив { #archive }

!!! abstract "Коротко"
    - **Где:** боковое меню → «Архив пользователей».
    - **Discord:** `/archive @участник`.

Люди, снятые с должности: должность, срок, когда поставлен и снят, кто снял, причина. Карточка сохраняется с историей должностей и выговоров. Вернулся — виден прошлый срок.

## Журнал { #log }

!!! abstract "Коротко"
    - **Где:** боковое меню → «Логи».
    - **Discord:** `/log @участник [с] [по]`.

Лента всех действий сервера: время, исполнитель, над кем, событие, статус, причина.

- Фильтры: период, событие, статус, поиск.
- Искать можно и по исполнителю, и по тому, над кем действие.
- Время — UTC+3.
- Записи показываются на языке панели. Причины, написанные людьми, не переводятся.

!!! info "Журнал нельзя изменить"
    Никто не может отредактировать или удалить запись — иначе журнал бесполезен как доказательство.

## Если не работает { #troubleshooting }

| Что видите | Почему | Что сделать |
|---|---|---|
| «Архив пользователя не найден» (бот) | Человек ни разу не снимался или ID с ошибкой | Проверьте упоминание или ID |
| Нужной записи нет в журнале | Включены фильтры или выбран не тот период | Снимите фильтры, расширьте период |
| Время сдвинуто на несколько часов | Журнал показывает UTC+3 | Учитывайте свой часовой пояс |
