# Документы

<p class="af-lead" markdown>Устав, правила, лекции и приказы — в одном месте и с поиском по тексту. Пишут вместе и вживую, как в Google Документах, а читают по ссылке.</p>

!!! abstract "Коротко"
    - **Где:** боковое меню → «Документооборот».
    - **Права:** «Создание», «Редактирование», «Удаление» в группе «Документы».
    - **Без права «Редактирование»** документ открывается ссылкой для чтения, а не в редакторе.

## Как пишут документ

- Нажмите **«Создать документ»** и выберите пустой лист или шаблон: устав, лекция, приказ, протокол, инструкция.
- Несколько человек правят документ одновременно. Всё сохраняется само, кнопки «Сохранить» нет.
- **«/»** открывает список блоков: заголовки, списки, таблица, картинка, код, выноска. **«@»** и ник отмечают участника, ему приходит уведомление.
- Выделите фразу и нажмите **«Комментировать»** — обсуждение откроется справа.
- Прошлые версии лежат в **истории**, любую можно вернуть в один клик.
- Кнопка со стрелками или **Ctrl+Shift+F** открывает документ на весь экран, **Esc** возвращает обычный вид.

## Кто может открыть документ

У каждого документа есть ссылка для чтения — кнопка **«Открыть»** в списке и в шапке документа. Кто её откроет, решается в окне **«Поделиться»**:

| Выбор | Кто откроет |
|---|---|
| **Пользователи A-Faction с этого сервера** | Только вошедшие через Discord и состоящие на вашем сервере |
| **Все, у кого есть ссылка** | Любой человек, без входа. Править и комментировать по ссылке нельзя |

### Только для нужных организаций и должностей

Если документ не для всего сервера, сузьте круг:

1. Откройте **«Поделиться»** и выберите **«Пользователи A-Faction с этого сервера»**.
2. В блоке **«Кто из участников»** нажмите **«Выбранные организации и должности»**.
3. Нажмите **«Организация или должность»** и отметьте нужное. Галочка у организации открывает документ ей целиком, галочки у должностей — только им. Например, весь ЛСПД и лидеры ФБР.

Выбор сохраняется сам. Остальные участники не увидят документ ни по ссылке, ни в списке. Тот, у кого есть право «Редактирование», видит документ всегда.

!!! tip "Список берётся из структуры"
    Организации и должности приходят из [Структуры](../settings/structure.md). Если список пустой, сначала заведите их там.

!!! danger "Удаление необратимо"
    Удалённый документ не восстановить. Подтверждение спрашивается один раз.

## Если не работает { #troubleshooting }

| Что видите | Почему | Что сделать |
|---|---|---|
| Нет кнопки «Создать документ» или правки | Нет права | [Права](../settings/access.md) |
| Документ открывается только для чтения | Нет права «Редактирование» | [Права](../settings/access.md) |
| «Нет доступа» — «Документ доступен только участникам своего сервера в A-Faction.» | Вы не состоите на сервере документа | Попросите ссылку для всех или вступите на сервер |
| «Нет доступа» — «Документ открыт только для отдельных организаций и должностей, и вашей среди них нет.» | Документ открыт не вашей организации или должности | Попросите того, кто правит документ, добавить вас в «Кто из участников» |
| «Документ недоступен» | Ссылка неверная или документ удалили | Попросите новую ссылку |
| Коллега не видит документ в списке | Его организации и должности нет в «Кто из участников» | Добавьте её или выберите «Весь сервер» |
| «Не удалось изменить доступ к документу» | Сбой или пропала связь | Повторите |
| «На сервере слишком много документов. Удалите ненужные и попробуйте снова.» | Достигнут предел документов на сервере | Удалите ненужные |
| «К серверу не привязан Discord, публиковать некуда.» | Не подключён бот | [Подключите бота](../start/connect-bot.md) |
