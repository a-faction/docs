# Документы

<p class="af-lead" markdown>Устав, правила, регламенты и таблицы — в одном месте и с поиском по тексту. Больше не нужно искать документ по закрепам.</p>

!!! abstract "Коротко"
    - **Где:** боковое меню → «Документооборот».
    - **Права:** «Создание», «Изменение», «Удаление» в группе «Документы».

- Вкладки **«Все»**, **«Документы»**, **«Таблицы»**.
- Поиск — по словам внутри текста, не только по названию.
- Документ принадлежит серверу, где создан.
- В таблицах можно добавлять колонки и строки.

!!! danger "Удаление необратимо"
    Удалённый документ не восстановить. Подтверждение спрашивается один раз.

## Если не работает { #troubleshooting }

| Что видите | Почему | Что сделать |
|---|---|---|
| Нет кнопки создания или правки | Нет права | [Права](../settings/access.md) |
| «Не удалось сохранить изменения» | Сбой или пропала связь | Не закрывайте страницу, повторите |
| «Нет документов» | Пока ничего не создано | — |
