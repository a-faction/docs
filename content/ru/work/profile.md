# Профиль участника

<p class="af-lead" markdown>Всё о человеке на одной странице: должность, срок, выговоры, коины, история. Отсюда же руководство повышает, наказывает и снимает — и каждое действие сразу попадает в журнал.</p>

!!! abstract "Коротко"
    - **Где:** нажмите на ник человека в любом месте панели. Свой профиль — меню в шапке → «Профиль».
    - **Действия:** только по правам и только над теми, кто [младше по должности](../settings/hierarchy.md).

## Что в профиле

- аватар, ник, подразделение, должность, срок;
- соцсети, возраст, Discord ID (если не скрыты);
- баланс коинов, выговоры, иммунитеты;
- неактив — значок с датой окончания;
- достижения, оформление Premium;
- онлайн: «Сейчас» или «не в сети · когда».

**Несколько серверов:** вверху вкладки серверов. Все цифры — по открытой вкладке.

## Вкладки

- **«История руководителя»** (у руководства — **«История администратора»**) — одна лента событий по дате: выговоры, неактивы, изменения срока, коины, отчёты. Каждая запись — фраза: «Администратор Иван выдал строгий выговор. Причина: …».
- **«Архив»** — прошлые должности.

## Значки в шапке профиля

| Значок | Значение |
|---|---|
| :material-crown: | Активен Premium |
| :material-eye-off: | Человек скрыл часть данных. Наведите — список скрытого |
| :material-image: | Смена обоев (только в своём профиле) |
| :material-brain: | [Разбор работы от ИИ](../help/ai.md#member-review) |

## Действия руководства { #actions }

| Действие | Что делает | Нужное право |
|---|---|---|
| Выговор | Выдать или снять — [подробнее](reprimands.md) | Строгие / Устные / Министерские |
| Иммунитет | Выдать или снять защиту от выговоров | Иммунитет |
| Коины | Начислить или списать | Коины |
| Изменить данные | Ник, контакты, возраст | Данные |
| Сменить подразделение/должность, добавить новую должность | Перевод внутри сервера | Фракция/должность (у руководства — Должность админа) |
| Изменить срок | Сдвинуть дату окончания должности (до 365 дней за раз), дни неактива учитываются | Срок |
| Снять с должности | Снимает роли в Discord, переносит в архив. Причина обязательна | Удаление (у руководства — Снятие) |

Только администрация платформы: достижения, Premium, блокировка аккаунта.

Руководство видит и поля, скрытые [приватностью](../account/privacy.md).

## Если не работает { #troubleshooting }

| Что видите | Почему | Что сделать |
|---|---|---|
| Нет кнопок действий | Нет прав или человек старше вас | См. [Права](../settings/access.md) и [Старшинство](../settings/hierarchy.md) |
| «Должность стоит выше вашей — действие недоступно» | Человек старше или на вашем уровне | Действие делает кто-то старше |
| «Это действие нельзя применить к себе» | Административные действия над собой запрещены | Попросите другого руководителя |
| Цифры не те | Открыта вкладка другого сервера | Переключите вкладку сервера |
| «Игрок не найден» | Человека сняли или удалили | Обновите страницу, проверьте [архив](archive-logs.md) |
| «Введите корректное число, отличное от 0» | Коины: пустое или нулевое значение | Введите число. Для списания — со знаком минус |
| «Максимально допустимое значение — 365 дней» | Слишком большой сдвиг срока | Сдвиньте частями |
| «Укажите причину снятия» | Пустая причина | Заполните |
| «Не удалось снять роли Discord — продолжаем» | Роль бота ниже снимаемой | Снятие выполнено, уберите роли вручную |
| «Менять должности этим действием нельзя» | Должность меняется только через «Сменить подразделение/должность» | Используйте нужное действие |
| «Ник игрока не может быть пустым» | Пустой ник | Заполните |
| Данные скрыты | Человек включил приватность | Видно только руководству |
