# Формы и анкеты

<p class="af-lead">Свои анкеты, опросы и тесты по ссылке — как Google Forms, но внутри A-Faction.</p>

!!! abstract "Коротко"
    - **Где:** боковое меню → «Формы».
    - **Доступ:** видимость пункта «Формы» + право «Формы» (Создание и ответы). Владелец — всегда.
    - **Ссылка:** `crm.a-faction.xyz/f/код`.
    - **Лимиты:** 200 форм на сервер, 60 вопросов в форме.

!!! note "Не путать с «Формами Discord»"
    [Формы Discord](../discord/discord-forms.md) — кнопки и меню бота внутри Discord. Здесь — анкеты в браузере.

## Создать

<div class="af-steps" markdown>

1. **«Новая форма»**.
2. В центре впишите название, описание, вопросы — прямо на листе, как увидит человек.
3. Слева «Структура» — перетаскивайте вопросы и страницы.
4. Справа — тип ответа и «Обязательный» для выбранного вопроса. Ничего не выбрано — настройки формы.
5. **«Сохранить»** или ++ctrl+s++.
6. **«Скопировать ссылку»** и отправьте людям.

</div>

## Типы вопросов

| Тип | Ответ |
|---|---|
| Строка | Короткий текст |
| Абзац | Длинный текст |
| Один вариант | Один из списка |
| Несколько | Несколько из списка |
| Список | Выпадающий список |
| Число | Число |
| Дата | Дата |
| Шкала | От 2 до 10 делений |
| Картинка | Блок с картинкой и подписью, без ответа |
| Ник / Организация / Должность | Заполняются сами из профиля. Только в формах «Только пользователи A-Faction» |

Картинка к любому вопросу — справа, «Картинка к вопросу». **«+ Страница»** — новая страница, человек листает «Далее» / «Назад».

## Настройки формы

=== "Основное"

    - **Кто может отвечать:** «Все по ссылке» (без входа) или «Только пользователи A-Faction» (вход через Discord, в ответах виден ник).
    - **Принимать до** — дата и время автоматического закрытия.
    - **Только один ответ** — по аккаунту для пользователей A-Faction, по браузеру для всех.
    - **Сообщение после отправки.**
    - Переключатель **«Принимает ответы»** в шапке работает сразу, без сохранения.

=== "Оформление"

    Темы: Ночь, Бумага, Океан, Лес, Закат, Терминал. Или вручную: фон (цвет, картинка, затемнение, размытие), цвета карточки, текста, акцента, прозрачность, шрифты, размеры, ширина, скругление, положение заголовка, баннер.

=== "Тест"

    - **Правильные ответы** — галочка у варианта. «Один вариант» и «Список» — один правильный, «Несколько» — любое число, засчитывается только точный набор. Заполняющий ключ не видит.
    - **Время** — 1–600 минут. Таймер стартует после «Начать», не сбрасывается перезагрузкой. Время вышло — форма отправляется сама.
    - **Анти-списывание** — замечает уход на другую вкладку, окно или программу, отключает копирование и вставку.
        - «Предупреждать» — после N уходов форма отправляется сама.
        - «Запрещать проходить» — первый уход закрывает тест, ответы стираются, повторно в этом браузере нельзя.
    - Время и число уходов видны в каждом ответе.

=== "Уведомления"

    - Колокольчик о новых ответах.
    - Канал Discord для карточек ответов.
    - **«Решать заявки из Discord»** — кнопки «Одобрить», «Отказать», «Вернуть в новые» на карточке. Решение синхронизируется в обе стороны.

## Ответы

Вкладка **«Ответы»**: сводка с графиками (правильный вариант — зелёным), список ответов со счётом «Правильно N из M», статусы «Принят» / «Отклонён», удаление, фильтр, выгрузка CSV (открывается в Excel). Новые ответы появляются сами.

## Если не работает — автору формы { #troubleshooting }

| Что видите | Почему | Что сделать |
|---|---|---|
| «Нет доступа к формам» | Нет права «Формы» | [Права](../settings/access.md) |
| «На сервере уже 200 форм» | Лимит | Удалите ненужные |
| «Достигнут предел — 60 вопросов» | Лимит | Разбейте на две формы |
| «Впишите текст вопроса» / «Добавьте хотя бы один вариант» / «Загрузите картинку» | Не заполнен вопрос | Заполните подсвеченный вопрос |
| «Шаблон работает только в форме для пользователей A-Faction» | Ник/Организация/Должность в открытой форме | «Кто может отвечать» → «Только пользователи A-Faction» |
| «Форма закрыта» / ответов нет | Выключен приём или прошла дата «Принимать до» | Включите «Принимает ответы», продлите срок |
| Карточки не приходят в Discord | Канал не выбран или у бота нет доступа | Проверьте канал во вкладке «Уведомления» |

## Если не работает — тому, кто заполняет

| Что видите | Почему | Что сделать |
|---|---|---|
| «Форма не найдена» | Ссылка с ошибкой или форму удалили | Уточните ссылку у автора |
| «Вы уже ответили» | Форма принимает один ответ | — |
| «Нет связи с сервером» | Пропал интернет | Проверьте связь и нажмите «Отправить» ещё раз. Ответы сохранены на странице |
| «Слишком часто» | Только что отправляли с этого адреса | Подождите несколько секунд |
| «Нужно войти заново» | Вход в A-Faction истёк | Обновите страницу, войдите через Discord |
| «Страница устарела» | Форму изменили | Обновите страницу и отправьте снова |
| «Пустой ответ» | Нет ни одного ответа | Ответьте хотя бы на один вопрос |
| «Сервер не смог сохранить ответ» | Сбой на нашей стороне | Повторите через минуту |
| «Тест закрыт» | Ушли со страницы в строгом режиме | Пройти заново нельзя — обратитесь к автору |
