## Пошук { #search }

Відкрити: ++ctrl+k++ (Mac: ++cmd+k++), клавіша ++slash++ поза полем введення або поле в шапці.

Знаходить: розділи меню, розділи налаштувань (якщо є доступ), людей поточного сервера, статті довідки, сповіщення й дії — відкрити ШІ, написати в підтримку, прочитати всі сповіщення, змінити тему, мову чи щільність, почати екскурсію, вийти.

| Знак на початку | Шукає лише |
|---|---|
| `/` | розділи |
| `@` | людей |
| `?` | довідку |
| `!` | сповіщення |
| `>` | дії |

++tab++ — змінити область, стрілки — вибір, ++enter++ — відкрити, ++esc++ — закрити.

На сторінках зі списками є своє поле пошуку. Запит зберігається в адресі — посиланням можна поділитися.

## Сповіщення { #notifications }

Дзвіночок і сторінка «Сповіщення» показують одне й те саме:

- дії над вами (догана, схвалений звіт тощо);
- відповіді підтримки, рішення за заявками, нагадування автоматизацій;
- нова версія панелі.

Вкладки: «Усі», «Непрочитані»; на сторінці ще «Повідомлення» і «Журнал». Прочитаним стає те, на що натиснули, або все — **«Прочитати все»**. Відкриття дзвіночка нічого не позначає. Позначки синхронізуються між пристроями.

## Екскурсія сайтом

Покроковий тур: підсвічує справжню кнопку й пояснює її. Пропускає недоступні вам розділи.

Запуск: **«Почати знайомство із сайтом»** у вікні підтримки чи на головній нового сервера, через пошук або **Налаштування сайту → Допомога → Знайомство із сайтом**. Керування: ++arrow-left++ ++arrow-right++, ++enter++, ++esc++.

## Якщо не працює { #troubleshooting }

| Що бачите | Чому | Що зробити |
|---|---|---|
| «Доступ обмежено… обмежено налаштуваннями сайту» | Розділ приховано для вашої посади | Попросіть адміністрацію — [Права](../settings/access.md) |
| «Немає з'єднання» | Зник інтернет | Панель підключиться сама, коли зв'язок повернеться |
| «Сайт недоступний» | Сервер перезапускається або доступ ріже провайдер | Зачекайте хвилину. Не допомагає — спробуйте VPN, перевірте [статус](../help/status.md) |
| «Технічні роботи» | Тривають роботи | Натисніть «Перевірити знову» пізніше |
| Смуга «Виявлено збій у роботі сервісів» | Збій уже виявлено | Нічого робити не треба, ми лагодимо |
| «Закрити без збереження?» | У вікні є введені дані | «Скасувати» — повернутися до заповнення |
| Дивні відмови після довгої перерви | Застаріла вкладка | Оновіть сторінку |
