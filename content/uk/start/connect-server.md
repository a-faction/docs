# Підключити сервер

<p class="af-lead" markdown>Чотири кроки й дві хвилини — і ваш Discord-сервер підключено до A-Faction. Платити нічого не потрібно, картка не знадобиться.</p>

!!! abstract "Коротко"
    - **Де:** [a-faction.xyz](https://a-faction.xyz) → «Підключити сервер». У панелі такої кнопки немає.
    - **Що потрібно:** Discord-акаунт і права адміністратора на своєму Discord-сервері.
    - **Обмеження:** одна людина може володіти лише одним сервером.

## Кроки

<div class="af-steps" markdown>

1. **Акаунт і сервер.** Введіть свій Discord ID або нікнейм та ID Discord-сервера. Натисніть **«Отримати код»**.
2. **Код із Discord.** Бот надішле в особисті повідомлення код із 6 цифр — введіть його.
3. **Бот на сервері.** Натисніть **«Додати бота»**, виберіть свій сервер, підтвердьте права, поверніться й натисніть **«Перевірити наявність бота»**.
4. **Дані сервера.** Назва (підставиться сама), категорія, ваш нікнейм, ім'я, вік (14–80), соцмережі за бажанням. Натисніть **«Зареєструвати сервер»**.
5. **Вхід.** Натисніть **«Відкрити CRM»** і увійдіть через Discord — профіль власника вже створено. **«Отримати ролі»** видасть вам ролі в Discord.

</div>

Після цього панель порожня — це нормально. Далі: [перше налаштування](first-steps.md).

## Як дізнатися ID

Нік можна змінити, а ID — це постійний номер із 17–20 цифр.

<div class="af-steps" markdown>

1. Discord → **Налаштування користувача → Розширені** → увімкніть **«Режим розробника»**.
2. ID сервера: правою кнопкою по серверу в списку ліворуч → **«Копіювати ID сервера»**.
3. Свій ID: правою кнопкою по своєму аватару → **«Копіювати ID користувача»**.

</div>

## Правила коду

- Діє **10 хвилин**, підходить **один раз**.
- Надіслати можна до **3 разів**, ввести — до **10 разів** за 15 хвилин.

## Якщо не працює { #troubleshooting }

| Що бачите | Чому | Що зробити |
|---|---|---|
| Код не приходить | Бот пише лише тим, з ким у нього спільний сервер, і лише якщо відкриті особисті повідомлення | Зайдіть на [Discord-сервер A-Faction](https://discord.gg/2cMBp8gjYn), у Discord увімкніть **Конфіденційність → Особисті повідомлення від учасників сервера**, натисніть **«Надіслати ще раз»** |
| «Код уже отправлялся несколько раз. Подождите 15 минут» (код уже надсилався кілька разів) | Перевищено ліміт надсилань | Зачекайте 15 хвилин |
| «Код не найден. Запросите новый» / «Код уже был использован» | Код минув (10 хвилин) або вже введений | Запросіть новий код |
| Бот не знаходиться на кроці 3 | Бота додали на інший сервер або не підтвердили запрошення | Натисніть «Додати бота» ще раз і виберіть саме той сервер, ID якого ввели |
| «Сервер з таким Discord ID вже зареєстровано» | Discord-сервер уже підключено | Якщо це ваш сервер — напишіть у [підтримку](../help/support.md) |
| «Цей Discord-акаунт вже є власником зареєстрованого сервера» | Володіти можна лише одним сервером | Використовуйте наявний або напишіть у підтримку |
| «Реєстрацію зупинено» | Збій на одному з кроків | Повторіть. Не допомогло — [підтримка](../help/support.md) |
