# Вхід і пристрої

<p class="af-lead" markdown>Жодних паролів: в A-Faction ви входите своїм Discord-акаунтом. Один раз увійшли — і панель запам'ятає вас надовго.</p>

!!! abstract "Коротко"
    - **Де:** [crm.a-faction.xyz](https://crm.a-faction.xyz) → **«Увійти через Discord»**.
    - **Скільки триває вхід:** довго, входити щодня не потрібно.
    - **Усі входи:** розділ «Сесії».

## Як увійти

<div class="af-steps" markdown>

1. Відкрийте [crm.a-faction.xyz](https://crm.a-faction.xyz) і натисніть **«Увійти через Discord»**.
2. У Discord натисніть **«Авторизувати»**.
3. Ви повернетеся в панель.

</div>

Увійти може лише той, хто є в складі хоча б одного сервера. Немає свого сервера — потрібна [реєстрація](../work/members.md#register) або [підключення свого](connect-server.md).

!!! tip "Захистіть Discord"
    Власної двоетапної перевірки в панелі немає — її дає Discord. Увімкніть у Discord: **Налаштування → Мій обліковий запис → Двофакторна автентифікація**.

## Сесії { #sessions }

Розділ **«Сесії»** — усі пристрої, де виконано вхід: пристрій, адреса, час входу та останньої активності.

- завершити одну сесію — кнопка біля рядка;
- **«Вийти»** — на цьому пристрої;
- **«Вийти з усіх»** — скрізь.

!!! warning "Заходили з чужого комп'ютера"
    Закрити вкладку недостатньо — завершіть сесію в «Сесіях».

## Кілька серверів

Перемикач серверів — у шапці. У кожного сервера свої дані, права й назви, тож панель після перемикання може виглядати інакше.

## Якщо не працює { #troubleshooting }

| Що бачите | Чому | Що зробити |
|---|---|---|
| «Доступ заборонено. У вас немає доступу до цієї системи» | Вашого Discord-акаунта немає в складі жодного сервера | Попросіть керівництво зареєструвати вас |
| «Вас немає на жодному сервері» | Вас зняли з усіх серверів | Попросіть керівництво додати вас знову або [підключіть свій сервер](connect-server.md) |
| «Ви скасували авторизацію в Discord» | У вікні Discord натиснули «Скасувати» | Увійдіть знову й натисніть «Авторизувати» |
| «Сесія авторизації минула» | Вікно входу було відкрите надто довго | Натисніть «Увійти через Discord» знову |
| «Discord не повернув код авторизації» / «Не вдалося отримати токен від Discord» / «Не вдалося отримати дані профілю Discord» | Збій зв'язку з Discord | Спробуйте ще раз за хвилину. Перевірте [статус](../help/status.md) |
| «Сервер перевантажений» | Тимчасове перевантаження | Повторіть за кілька секунд |
| «Внутрішня помилка сервера» і код | Збій на нашому боці | Спробуйте пізніше. Не допомогло — напишіть у [підтримку](../help/support.md) і вкажіть код |
| «Акаунт заблоковано» | Блокування захисту або адміністрації | Див. [Блокування](../help/troubleshooting.md#blocked) |
| «Сервер заморожено» | Сервер призупинено адміністрацією платформи | Напишіть у [підтримку](../help/support.md) |
| «Цей сервер вам недоступний» / «Не вдалося змінити сервер» | Вас зняли з цього сервера або немає зв'язку | Оновіть сторінку |
| «Сесій не знайдено» | Вхід застарів | Оновіть сторінку або увійдіть знову |
| Постійно викидає з панелі | Браузер видаляє дані сайтів або блокує сторонні дані | Дозвольте зберігати дані для crm.a-faction.xyz, вимкніть очищення під час закриття |
