# Застосунок для комп'ютера

<p class="af-lead" markdown>Любите, коли все під рукою? Встановіть A-Faction як звичайну програму — свій ярлик, своє вікно, оновлення приходять самі.</p>

!!! abstract "Коротко"
    - **Завантажити:** [a-faction.xyz/desktop](https://a-faction.xyz/desktop) — сайт сам запропонує потрібну версію.
    - **Оновлення:** приходять самі.
    - **Вхід:** через Discord.

## Встановлення

<div class="af-steps" markdown>

1. Відкрийте [a-faction.xyz/desktop](https://a-faction.xyz/desktop) і завантажте версію для своєї системи.
2. Запустіть завантажений файл і дотримуйтеся інсталятора.
3. Відкрийте застосунок і натисніть «Увійти через Discord».

</div>

## Телефон

Окремого застосунку для телефона немає. Відкрийте [crm.a-faction.xyz](https://crm.a-faction.xyz) у браузері й виберіть у меню браузера **«Додати на головний екран»** — панель відкриватиметься як застосунок.

## Якщо не працює { #troubleshooting }

| Що бачите | Чому | Що зробити |
|---|---|---|
| Windows: «Windows захистив ваш комп'ютер» | Збірка не має платного підпису видавця | Натисніть **«Докладніше» → «Виконати в будь-якому разі»** |
| macOS: «Не вдається відкрити застосунок» | Захист macOS для застосунків з інтернету | Правою кнопкою по застосунку → **«Відкрити»** → **«Відкрити»** |
| Застосунок не оновлюється | Немає зв'язку із сервером оновлень | Перезапустіть застосунок. Не допомогло — завантажте знову із сайту |
| Білий екран | Збій завантаження | Перезапустіть. Перевірте [статус](../help/status.md) |
