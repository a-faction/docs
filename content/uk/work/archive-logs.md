# Архів і журнал

<p class="af-lead" markdown>Нічого не губиться: ті, хто пішов, ідуть в архів разом з історією, а журнал назавжди пам'ятає, хто, кому і що зробив.</p>

## Архів { #archive }

!!! abstract "Коротко"
    - **Де:** бічне меню → «Архів учасників».
    - **Discord:** `/archive @учасник`.

Люди, зняті з посади: посада, термін, коли призначений і знятий, хто зняв, причина. Картка зберігається з історією посад і доган. Повернувся — видно минулий термін.

## Журнал { #log }

!!! abstract "Коротко"
    - **Де:** бічне меню → «Логи».
    - **Discord:** `/log @учасник [з] [по]`.

Стрічка всіх дій сервера: час, виконавець, над ким, подія, статус, причина.

- Фільтри: період, подія, статус, пошук.
- Шукати можна і за виконавцем, і за тим, над ким дія.
- Час — UTC+3.
- Записи показуються мовою панелі. Причини, написані людьми, не перекладаються.

!!! info "Журнал не можна змінити"
    Ніхто не може відредагувати чи видалити запис — інакше журнал марний як доказ.

## Якщо не працює { #troubleshooting }

| Що бачите | Чому | Що зробити |
|---|---|---|
| «Архив пользователя не найден» (бот: архів не знайдено) | Людину жодного разу не знімали або ID із помилкою | Перевірте згадку чи ID |
| Потрібного запису немає в журналі | Увімкнені фільтри або вибрано не той період | Зніміть фільтри, розширте період |
| Час зсунутий на кілька годин | Журнал показує UTC+3 | Враховуйте свій часовий пояс |
