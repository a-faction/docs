# Форми та анкети

<p class="af-lead" markdown>Власні Google Forms просто в A-Faction: заявки до складу, опитування, тести на знання правил — із таймером і захистом від списування.</p>

!!! abstract "Коротко"
    - **Де:** бічне меню → «Форми».
    - **Доступ:** видимість пункту «Форми» + право «Форми» (Створення та відповіді). Власник — завжди.
    - **Посилання:** `crm.a-faction.xyz/f/код`.
    - **Ліміти:** 200 форм на сервер, 60 питань у формі.

!!! note "Не плутати з «Формами Discord»"
    [Форми Discord](../discord/discord-forms.md) — кнопки й меню бота всередині Discord. Тут — анкети в браузері.

## Створити

<div class="af-steps" markdown>

1. **«Нова форма»**.
2. У центрі впишіть назву, опис, питання — просто на аркуші, як побачить людина.
3. Ліворуч «Структура» — перетягуйте питання й сторінки.
4. Праворуч — тип відповіді та «Обов'язкове» для вибраного питання. Нічого не вибрано — налаштування форми.
5. **«Зберегти»** або ++ctrl+s++.
6. **«Скопіювати посилання»** і надішліть людям.

</div>

## Типи питань

| Тип | Відповідь |
|---|---|
| Рядок | Короткий текст |
| Абзац | Довгий текст |
| Один варіант | Один зі списку |
| Кілька | Кілька зі списку |
| Список | Випадний список |
| Число | Число |
| Дата | Дата |
| Шкала | Від 2 до 10 поділок |
| Картинка | Блок із картинкою й підписом, без відповіді |
| Нік / Організація / Посада | Заповнюються самі з профілю. Лише у формах «Лише користувачі A-Faction» |

Картинка до будь-якого питання — праворуч, «Картинка до питання». **«+ Сторінка»** — нова сторінка, людина гортає «Далі» / «Назад».

## Налаштування форми

=== "Основне"

    - **Хто може відповідати:** «Усі за посиланням» (без входу) або «Лише користувачі A-Faction» (вхід через Discord, у відповідях видно нік).
    - **Приймати до** — дата й час автоматичного закриття.
    - **Лише одна відповідь** — за акаунтом для користувачів A-Faction, за браузером для всіх.
    - **Повідомлення після надсилання.**
    - Перемикач **«Приймає відповіді»** в шапці працює одразу, без збереження.

=== "Оформлення"

    Теми: Ніч, Папір, Океан, Ліс, Захід, Термінал. Або вручну: фон (колір, картинка, затемнення, розмиття), кольори картки, тексту, акценту, прозорість, шрифти, розміри, ширина, заокруглення, положення заголовка, банер.

=== "Тест"

    - **Правильні відповіді** — галочка біля варіанта. «Один варіант» і «Список» — один правильний, «Кілька» — будь-яка кількість, зараховується лише точний набір. Той, хто заповнює, ключа не бачить.
    - **Час** — 1–600 хвилин. Таймер стартує після «Почати», не скидається перезавантаженням. Час минув — форма надсилається сама.
    - **Анти-списування** — помічає перехід на іншу вкладку, вікно чи програму, вимикає копіювання та вставлення.
        - «Попереджати» — після N переходів форма надсилається сама.
        - «Забороняти проходити» — перший перехід закриває тест, відповіді стираються, повторно в цьому браузері не можна.
    - Час і кількість переходів видно в кожній відповіді.

=== "Сповіщення"

    - Дзвіночок про нові відповіді.
    - Канал Discord для карток відповідей.
    - **«Вирішувати заявки з Discord»** — кнопки «Схвалити», «Відмовити», «Повернути в нові» на картці. Рішення синхронізується в обидва боки.

## Відповіді

Вкладка **«Відповіді»**: зведення з графіками (правильний варіант — зеленим), список відповідей із рахунком «Правильно N з M», статуси «Прийнято» / «Відхилено», видалення, фільтр, вивантаження CSV (відкривається в Excel). Нові відповіді з'являються самі.

## Якщо не працює — автору форми { #troubleshooting }

| Що бачите | Чому | Що зробити |
|---|---|---|
| «Немає доступу до форм» | Немає права «Форми» | [Права](../settings/access.md) |
| «На сервері вже 200 форм» | Ліміт | Видаліть зайві |
| «Досягнуто межі — 60 питань» | Ліміт | Розбийте на дві форми |
| «Впишіть текст питання» / «Додайте хоча б один варіант» / «Завантажте картинку» | Не заповнено питання | Заповніть підсвічене питання |
| «Шаблон працює лише в формі для користувачів A-Faction» | Нік/Організація/Посада у відкритій формі | «Хто може відповідати» → «Лише користувачі A-Faction» |
| «Форму закрито» / відповідей немає | Вимкнено приймання або минула дата «Приймати до» | Увімкніть «Приймає відповіді», продовжте термін |
| Картки не приходять у Discord | Канал не вибрано або бот не має доступу | Перевірте канал у вкладці «Сповіщення» |

## Якщо не працює — тому, хто заповнює

| Що бачите | Чому | Що зробити |
|---|---|---|
| «Форму не знайдено» | Посилання з помилкою або форму видалили | Уточніть посилання в автора |
| «Ви вже відповіли» | Форма приймає одну відповідь | — |
| «Немає зв'язку із сервером» | Зник інтернет | Перевірте зв'язок і натисніть «Надіслати» ще раз. Відповіді збережено на сторінці |
| «Занадто часто» | Щойно надсилали з цієї адреси | Зачекайте кілька секунд |
| «Потрібно увійти знову» | Вхід в A-Faction минув | Оновіть сторінку, увійдіть через Discord |
| «Сторінка застаріла» | Форму змінили | Оновіть сторінку й надішліть знову |
| «Порожня відповідь» | Немає жодної відповіді | Дайте відповідь хоча б на одне питання |
| «Сервер не зміг зберегти відповідь» | Збій на нашому боці | Повторіть за хвилину |
| «Тест закрито» | Пішли зі сторінки в суворому режимі | Пройти знову не можна — зверніться до автора |
