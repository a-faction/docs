# Профіль учасника

<p class="af-lead" markdown>Усе про людину на одній сторінці: посада, термін, догани, коїни, історія. Звідси ж керівництво підвищує, карає й знімає — і кожна дія одразу потрапляє в журнал.</p>

!!! abstract "Коротко"
    - **Де:** натисніть на нік людини будь-де в панелі. Свій профіль — меню в шапці → «Профіль».
    - **Дії:** лише за правами й лише над тими, хто [молодший за посадою](../settings/hierarchy.md).

## Що в профілі

- аватар, нік, підрозділ, посада, термін;
- соцмережі, вік, Discord ID (якщо не приховані);
- баланс коїнів, догани, імунітети;
- неактив — значок із датою завершення;
- досягнення, оформлення Premium;
- онлайн: «Зараз» або «не в мережі · коли».

**Кілька серверів:** угорі вкладки серверів. Усі цифри — за відкритою вкладкою.

## Вкладки

- **«Історія керівника»** (у керівництва — **«Історія адміністратора»**) — одна стрічка подій за датою: догани, неактиви, зміни терміну, коїни, звіти. Кожен запис — фраза: «Адміністратор Іван видав сувору догану. Причина: …».
- **«Архів»** — минулі посади.

## Значки в шапці профілю

| Значок | Значення |
|---|---|
| :material-crown: | Активний Premium |
| :material-eye-off: | Людина приховала частину даних. Наведіть — список прихованого |
| :material-image: | Зміна шпалер (лише у своєму профілі) |
| :material-brain: | [Розбір роботи від ШІ](../help/ai.md#member-review) |

## Дії керівництва { #actions }

| Дія | Що робить | Потрібне право |
|---|---|---|
| Догана | Видати чи зняти — [докладніше](reprimands.md) | Суворі / Усні / Міністерські |
| Імунітет | Видати чи зняти захист від доган | Імунітет |
| Коїни | Нарахувати чи списати | Коїни |
| Змінити дані | Нік, контакти, вік | Дані |
| Змінити підрозділ/посаду, додати нову посаду | Переведення в межах сервера | Фракція/посада (у керівництва — Посада адміна) |
| Змінити термін | Зсунути дату завершення посади (до 365 днів за раз), дні неактиву враховуються | Термін |
| Зняти з посади | Знімає ролі в Discord, переносить в архів. Причина обов'язкова | Видалення (у керівництва — Зняття) |

Лише адміністрація платформи: досягнення, Premium, блокування акаунта.

Керівництво бачить і поля, приховані [приватністю](../account/privacy.md).

## Якщо не працює { #troubleshooting }

| Що бачите | Чому | Що зробити |
|---|---|---|
| Немає кнопок дій | Немає прав або людина старша за вас | Див. [Права](../settings/access.md) і [Старшинство](../settings/hierarchy.md) |
| «Посада стоїть вище за вашу, тож дія недоступна» | Людина старша або на вашому рівні | Дію виконує хтось старший |
| «Цю дію не можна застосувати до себе» | Адміністративні дії над собою заборонені | Попросіть іншого керівника |
| Цифри не ті | Відкрита вкладка іншого сервера | Перемкніть вкладку сервера |
| «Гравця не знайдено» | Людину зняли чи видалили | Оновіть сторінку, перевірте [архів](archive-logs.md) |
| «Введіть коректне число, відмінне від 0» | Коїни: порожнє або нульове значення | Введіть число. Для списання — зі знаком мінус |
| «Максимально допустиме значення — 365 днів» | Завеликий зсув терміну | Зсуньте частинами |
| «Вкажіть причину зняття» | Порожня причина | Заповніть |
| «Не вдалося зняти ролі Discord — продовжуємо» | Роль бота нижча за ту, що знімається | Зняття виконано, приберіть ролі вручну |
| «Змінювати посади цією дією не можна» | Посада змінюється лише через «Змінити підрозділ/посаду» | Використайте потрібну дію |
| «Нік гравця не може бути порожнім» | Порожній нік | Заповніть |
| Дані приховані | Людина ввімкнула приватність | Видно лише керівництву |
