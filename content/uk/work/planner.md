# Планувальник

<p class="af-lead" markdown>Розклад, у якому неможливо накластися: учасники самі займають вільний час, а система не дасть двом узяти один слот.</p>

!!! abstract "Коротко"
    - **Де:** бічне меню → «Планувальник».
    - **Час:** UTC+3, однаковий для всіх учасників.
    - **Налаштування:** Налаштування сайту → [Планувальник](../settings/planner.md).

## Зайняти слот

Натисніть на вільну клітинку. Слот займається одразу або після вікна підтвердження — як налаштовано. У клітинці з'явиться підрозділ, посада або нік.

## Правила

- зайнятий слот зайняти не можна;
- минулий час — лише якщо дозволено;
- сусідні слоти блокуються на задану кількість хвилин;
- скасувати може той, хто зайняв, або керівництво;
- зміни інших видно одразу.

## Минулі дні

Стрілки по днях і календар (крапкою позначено дні із записами). Минулі дні — лише перегляд.

## Новий день

Сітка очищається сама опівночі за часом панелі (UTC+3). Старі дні лишаються в історії.

## Якщо не працює { #troubleshooting }

| Що бачите | Чому | Що зробити |
|---|---|---|
| Час «не збігається» з моїм | Панель працює за UTC+3 для всіх | Враховуйте різницю зі своїм часовим поясом |
| «Не вдалося зайняти слот» | Слот щойно зайняли або його блокує сусідній | Виберіть інший |
| Не можна зайняти минулий час | Заборонено налаштуваннями | — |
| «У налаштуваннях не вибрано, що вказувати при занятті» | Не налаштовано | Адміністрації: [Планувальник](../settings/planner.md) → «Що вказувати» |
| «Немає даних про фракцію» / «про посаду» | У вас немає посади на цьому сервері | Перемкніть сервер |
| «Цього дня слоти не займали» | Порожній день | Виберіть день із крапкою в календарі |
| «Не вдалося скасувати слот» | Слот чужий | Скасовує власник слота або керівництво |
