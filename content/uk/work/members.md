# Учасники та реєстрація

<p class="af-lead" markdown>Увесь склад — в одній таблиці. Знайти людину, відфільтрувати за відділом чи зареєструвати новачка — кілька кліків, а ролі в Discord бот видасть сам.</p>

!!! abstract "Коротко"
    - **Де:** бічне меню → «Учасники».
    - **Реєструвати:** потрібне право «Реєстрація» (учасників) або «Реєстрація» в групі «Адміністрація» (керівництва).
    - **З Discord:** `/registration @учасник`.

## Таблиця

- **Фільтри + пошук.** Спершу застосовуються фільтри, потім пошук шукає серед відфільтрованих. Увімкнені фільтри видно під пошуком, знімаються одним натисканням.
- **Профіль** відкривається натисканням на нік — будь-де в панелі.
- **Колонки** однакові для всіх керівників сервера. Змінює адміністрація: [Таблиця учасників](../settings/table.md).
- **Телефон:** таблиця перетворюється на картки.
- **Неактив** людини видно просто в рядку.

## Реєстрація { #register }

### У панелі

<div class="af-steps" markdown>

1. «Учасники» → **«Створити»**.
2. Введіть Discord ID людини. Панель перевірить, що вона є на вашому Discord-сервері, і звірить її з [чорним списком](blacklist.md).
3. Виберіть підрозділ, посаду й термін.
4. Заповніть нік, ім'я, вік, соцмережі (ВКонтакте й Telegram — окремі необов'язкові поля).
5. Збережіть і дочекайтеся завершення кроків.

</div>

Далі автоматично: видача ролей у Discord, запис у журнал, привітання людині в особисті повідомлення. Перебіг видно за кроками у вікні.

### Через Discord

`/registration @учасник` → бот запитає підрозділ, посаду й дані. Права ті самі, що й у панелі.

### Обмеження

- Не можна видати посаду вищу за свою чи рівну — її не буде в списку. Див. [Старшинство](../settings/hierarchy.md).
- Заблокований акаунт зареєструвати не можна.
- Якщо людина вже є на цьому сервері, панель скаже: «Гравець уже зареєстрований на цьому сервері як …». Нову посаду додають через [зміну даних](profile.md#actions).

## Кілька спільнот

Один Discord-акаунт може бути в кількох серверах. У кожного сервера свої посади, нік та історія.

## Коли людина йде

Її не видаляють, а [знімають із посади](profile.md#actions) — вона переходить в [архів](archive-logs.md) з усією історією.

## Якщо не працює { #troubleshooting }

| Що бачите | Чому | Що зробити |
|---|---|---|
| Список порожній | Увімкнені фільтри або ще нікого не додали | Зніміть фільтри під пошуком. Перевірте, що налаштовано [структуру](../settings/structure.md) та посади |
| «Під поточні фільтри та пошук не підходить жоден запис» | Надто вузькі фільтри | Зніміть фільтри |
| Немає кнопки «Створити» | Немає права на реєстрацію | Попросіть адміністрацію — [Права](../settings/access.md) |
| «Discord ID не знайдено на Discord сервері» | Людини немає на вашому Discord-сервері або ID з помилкою | Запросіть людину на сервер, скопіюйте ID знову |
| «Цей акаунт заблоковано на A-Faction» | Акаунт заблокувала адміністрація платформи | Реєстрація неможлива |
| Реєстрацію зупинив чорний список | Людина в [чорному списку](blacklist.md) | Перевірте запис. Якщо помилка — виправте чи зніміть його |
| «Не вдалося перевірити чорний список» | Тимчасовий збій | Повторіть |
| «Недостатньо прав для реєстрації адміністрації» | Немає права на реєстрацію керівництва | Потрібне право «Реєстрація» в групі «Адміністрація» |
| «Не вдалося видати ролі Discord — продовжуємо без них» | Роль бота нижча за ту, що видається | Реєстрацію збережено. [Підніміть роль бота](../start/connect-bot.md#troubleshooting), видайте ролі вручну |
| «Ролі не видано: людини немає на Discord-сервері» | Людина не зайшла в Discord | Запросіть і видайте ролі вручну |
| «Особисте повідомлення не надіслано, але реєстрацію збережено» | У людини закриті особисті повідомлення | Нічого робити не треба |
| «Не вдалося завантажити аватар» | Збій завантаження картинки | Реєстрація не страждає, аватар можна поставити пізніше |
| «Фракції не налаштовані» | Немає підрозділів | Налаштуйте [структуру](../settings/structure.md) |
| Немає потрібної посади в списку | Вона вища за вашу або її немає в структурі | Див. [Старшинство](../settings/hierarchy.md) |
