# Зняття доган

<p class="af-lead" markdown>Оступився — можна виправитися. Людина просить зняти догану, отримує завдання, виконує його й приносить докази. Усе прозоро — і на сайті, і в Discord.</p>

!!! abstract "Коротко"
    - **Де:** бічне меню → «Догани».
    - **Подати:** будь-який учасник із доганою.
    - **Перевіряти:** право на догани, власник, адміністрація платформи або роль із налаштувань синхронізації.
    - **Одна відкрита заява** на один тип догани.

## Як іде заява

```
Очікування  →  Видано завдання  →  На перевірці  →  Схвалено / Відмовлено
```

## Подати

<div class="af-steps" markdown>

1. «Догани» → **«Новий запит»** → виберіть тип догани.
2. Дочекайтеся завдання. Воно прийде в сповіщення й в особисті повідомлення Discord із посиланням.
3. Виконайте завдання й натисніть **«Подати докази»**: посилання, скриншоти, опис.
4. Дочекайтеся рішення.

</div>

## Перевірити

- **Видати завдання** — заявам у статусі «Очікування».
- **Схвалити** — лише після доказів (статус «На перевірці»). У людини стане на одну догану менше, у журналі запис, у канал підрозділу — оголошення.
- **Відмовити** — у будь-якій незакритій заяві, навіть без доказів. Після відмови можна подати нову.
- Кілька заяв можна виділити й вирішити разом.

## Заяви в Discord { #discord }

Якщо ввімкнено синхронізацію ([Налаштування → Догани → Синхронізація](../settings/reprimands.md#sync)):

- на форумі висить тема з правилами й кнопкою **«Подати заяву»**;
- на кожну заяву бот створює гілку з кнопками **«Видати завдання»**, **«Подати докази»**, **«Схвалити»**, **«Відмовити»**;
- усе, що зроблено на сайті, повторюється в гілці, і навпаки.

## Якщо не працює { #troubleshooting }

| Що бачите | Чому | Що зробити |
|---|---|---|
| «На поточному сервері у вас немає активної фракції для подання заяви» | У вас немає посади на цьому сервері | Перемкніть сервер або зверніться до керівництва |
| «На обраній фракції немає доступних доган для зняття» | Знімати нічого | — |
| Не вдається вибрати тип у «Новий запит» | Уже є відкрита заява на цей тип | Дочекайтеся рішення |
| Немає кнопки «Подати докази» | Завдання ще не видано або ви не автор | Дочекайтеся завдання |
| «Виберіть заяви зі статусом „На перевірці“» | Схвалювати можна лише після доказів | Видайте завдання й дочекайтеся доказів |
| «Не вдалося схвалити заяву. Перевірте, що гравець існує…» | Людину зняли або в неї вже немає цієї догани | Відмовте в заяві |
| «У гравця вже немає цієї догани» | Догану зняли інакше | Відмовте в заяві |
| «Завдання видано, але сповіщення в ЛС не доставлено» | У людини закриті особисті повідомлення | Завдання видно на сайті, повідомте людину самі |
| «Дію виконано, але гілку в Discord не оновлено» | Бот не може писати у форум | Перевірте доступ бота до форуму |
| «Рішення застосовано, але сповіщення в Discord не надіслано» | Немає каналу підрозділу або доступу | Перевірте [канали](../settings/notifications.md) |
| Кнопки в темі Discord не працюють | Тему опублікували в іншому форумі заново | Видаліть стару тему вручну |
