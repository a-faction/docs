# Звітність

<p class="af-lead" markdown>Зробив роботу — прозвітуй і отримай нагороду. Учасник пише звіт з оформленням, керівник схвалює й одразу нараховує коїни.</p>

!!! abstract "Коротко"
    - **Де:** бічне меню → «Звітність».
    - **Подати:** будь-який учасник із посадою.
    - **Перевіряти:** право «Звіти».
    - **Виправити свій:** поки не перевірений.

## Подати

<div class="af-steps" markdown>

1. «Звітність» → **«Подати заяву»**.
2. Виберіть підрозділ і період.
3. Напишіть текст. Кнопки над полем: заголовок, жирний, курсив, закреслений, списки, завдання, цитата, код, посилання, розділювач. Клавіші: ++ctrl+b++, ++ctrl+i++, ++ctrl+k++.
4. Вкладка **«Попередній перегляд»** — так звіт побачить перевіряльник.
5. Надішліть. Статус — **«Очікує»**.

</div>

Максимум — 20 000 символів.

## Виправити

**«Змінити»** у рядку звіту або у вікні перегляду. Змінюються період і текст. Після рішення редагування закрите.

## Перевірити

- **Схвалити** + кількість коїнів — нарахується кожному вибраному учаснику.
- **Відхилити** — без нарахування.

Рішення — у журналі та в сповіщеннях автора.

Нагадування: «звіт без рішення N годин», «учасник не здає звіти N днів» — [автоматизації](../settings/notifications.md#automations).

## Якщо не працює { #troubleshooting }

| Що бачите | Чому | Що зробити |
|---|---|---|
| «Звіт порожній — напишіть хоча б один пункт» | Порожній текст | Заповніть |
| «Звіт задовгий — до 20 000 символів» | Перевищено обсяг | Скоротіть |
| «Дата початку не може бути пізніше дати завершення» | Переплутано дати | Виправте |
| «Вкажіть справжню дату — рік із чотирьох цифр» | Неправильна дата | Виправте |
| «Звіт уже перевірили — змінити його не можна» | Рішення ухвалено | Подайте новий звіт |
| «Змінювати можна лише свій звіт» | Чужий звіт | — |
| «… не знайдено в базі — можливо, знято з посади» | Автора зняли | Відхиліть звіт |
| Посада в гравця більше не числиться / немає посад — нараховувати нікуди | Посада змінилася | Відхиліть або нарахуйте коїни вручну |
| Немає кнопок «Схвалити» / «Відхилити» | Немає права «Звіти» | [Права](../settings/access.md) |
