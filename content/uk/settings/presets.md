# Пресети та назви

<p class="af-lead" markdown>Ваші слова й готові набори: перетворіть «фракції» на «відділи», а налаштування одного сервера перенесіть на інший за кілька кліків.</p>

!!! abstract "Коротко"
    - **Де:** Налаштування сайту → Пресети.

## Терміни

Змінюють лише підписи в усій панелі: «фракція» → «відділ», «коїни» → «бали». Однина й множина задаються окремо.

Готові набори: ігрова фракція, гільдія, кіберспортивна команда, команда модерації, волонтерська команда. Будь-яке слово — вручну. Дані й права не змінюються.

## Налаштування

Цілий набір: структура, права, догани, планувальник та інші розділи.

- **Вивантажити** налаштування свого сервера файлом.
- **Застосувати** готовий набір або файл. Крапки покажуть змінені розділи. Нічого не записано, поки не натиснете «Зберегти».

!!! info "Ніколи не переноситься"
    Прив'язка до Discord, канали, вебхуки та секрети.

## Якщо не працює { #troubleshooting }

| Повідомлення | Причина | Рішення |
|---|---|---|
| «Файл не схожий на шаблон налаштувань» | Не той файл | Виберіть файл, вивантажений з A-Faction |
| «Версія шаблону … підтримується …» | Старий формат | Вивантажте знову |
| «У шаблоні немає жодного переносимого налаштування» | Порожній файл | Вивантажте знову |
| Після застосування канали порожні | Канали не переносяться | Виберіть канали вручну |
