# Сповіщення та автоматизації

<p class="af-lead" markdown>Нехай система нагадує сама — про кінець відпустки, про завислий звіт, про зниклого учасника. А кожна подія йде в потрібний канал Discord.</p>

!!! abstract "Коротко"
    - **Де:** Налаштування сайту → Сповіщення. Автоматизації — там само, під каналами.
    - **Перевірка правил:** кожні 10 хвилин.

## Канали

Канал Discord на кожну тему: відпустки, догани, звіти, коїни, чорний список, активність.

- Канал підрозділу зі [Структури](structure.md) **важливіший** за загальний.
- Теми без каналу в Discord не пишуть, але сповіщення лишається в дзвіночку.

## Автоматизації { #automations }

Правила «якщо — то» без участі людей.

### Події

| Подія | Поріг |
|---|---|
| Закінчується неактив | За N днів |
| Починається неактив | — |
| Закінчується чорний список | За N днів |
| Звіт без рішення | N годин |
| Немає записів у журналі | N днів |
| Не здає звіти | N днів |
| Заява на зняття догани без рішення | N днів |
| Заявка на коїни без рішення | N днів |

### Дії

- **Сповістити учасника** або **керівництво** — людей або посаду (склад підставиться в момент надсилання).
- **Дублювати в особисті повідомлення** Discord.
- **Надіслати в канал** — канал за темою події (канал підрозділу важливіший).
- Підстановки: `{ник}`, `{дата}`, `{правило}`. Посилання — лише внутрішнє, починається з `/`.

### Створити

<div class="af-steps" markdown>

1. **«+ Правило»** або заготовка («Нагадати про кінець неактиву» — за 3 дні).
2. Назва, подія, поріг.
3. **«+ Дія»**: кому, заголовок, текст, ЛП, канал.
4. Збережіть.

</div>

Одне правило спрацьовує на один запис **один раз**.

## Якщо не працює { #troubleshooting }

| Повідомлення / ситуація | Причина | Рішення |
|---|---|---|
| «Не задано назву правила» | Порожньо | Заповніть |
| «Не вибрано подію» | Порожньо | Виберіть |
| «Потрібна хоча б одна дія» | Немає дій | «+ Дія» |
| «Дія N: не вибрано жодного отримувача» | Порожнє «Кому» | Виберіть людину або посаду |
| «Дія N: порожній заголовок сповіщення» | Порожньо | Заповніть |
| «Дія N: посилання має бути внутрішнім і починатися з «/»» | Зовнішнє посилання | Наприклад, `/inactive` |
| Правило не спрацювало | Ще не минуло 10 хвилин або вже спрацьовувало на цей запис | Зачекайте. Повторно на той самий запис не спрацює |
| У Discord не прийшло, у дзвіночку є | Для теми не вибрано канал | Виберіть канал |
| В ЛП не прийшло | У людини закриті особисті повідомлення | Дзвіночок отримає в будь-якому разі |
| У правила «помилка: …» | Останній запуск упав | Перевірте канали й отримувачів |
