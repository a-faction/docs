# Налаштування словами

<p class="af-lead" markdown>Просто напишіть, що змінити, — «додай відділ», «перейменуй посаду», — а ШІ підготує зміни й покаже їх до збереження.</p>

!!! abstract "Коротко"
    - **Де:** Налаштування сайту → Допомога → ШІ-помічник.
    - **Хто:** право «Доступ до налаштувань».

## Приклади

- «Додай організацію ФБР у Держструктури»
- «Перейменуй посаду Заступник на Заст. лідера»
- «Увімкни планувальник»
- «Постав Куратора вище за Лідера»
- «Додай причину реєстрації»

## Як працює

<div class="af-steps" markdown>

1. Напишіть, що змінити. Незрозуміло — ШІ перепитає.
2. ШІ покаже план — кожна зміна рядком із галочкою.
3. **«Додати в чернетку»** — зміни з'являться в налаштуваннях, але не збережуться.
4. **«Зберегти»** внизу. **«Скасувати»** — повернути.

</div>

| Уміє | Не вміє |
|---|---|
| Додавати й перейменовувати підрозділи, групи, посади, причини | Права на дії |
| Змінювати порядок (старшинство) | Ролі та канали Discord |
| Вмикати розділи | Терміни, ліміти доган |
| Змінювати назви (терміни) | Час планувальника, колонки, автоматизації |

Під час перейменування люди, права, канали й меню переїжджають самі. Видалити підрозділ із людьми не можна.

## Якщо не працює { #troubleshooting }

| Повідомлення | Причина | Рішення |
|---|---|---|
| «ШІ не відповів» | Тимчасовий збій | Повторіть або змініть вручну |
| Організація чи посада «… уже є» | Дубль | — |
| «… немає в налаштуваннях» | Помилка в назві | Напишіть назву, як у налаштуваннях |
| «… не в групі … — переставляти можна лише всередині групи» | Різні групи | Переставляйте в межах однієї групи |
| «Не вдалося порахувати учасників — застосувати план не можна» | Збій | Повторіть |
| «Права новій організації не видаються» | ШІ не змінює права | Призначте в [Правах](access.md) |
| «Повідомлення довше за N символів» | Задовго | Скоротіть |
