# Налаштування доган

<p class="af-lead" markdown>Налаштуйте дисципліну під свої правила: які бувають догани, скільки їх можна отримати й на що вони перетворюються, коли ліміт вичерпано.</p>

!!! abstract "Коротко"
    - **Де:** Налаштування сайту → Догани.
    - **Вкладки:** «Типи» та «Синхронізація».

## Типи

| Налаштування | Що задає |
|---|---|
| Назва | Як тип називається у вас |
| Ліміт | Максимум доган цього типу в однієї людини. «Без ліміту» — зняти обмеження |
| Хто видає | Через права «Суворі», «Усні», «Міністерські» |
| Ескалація | Коли досягнуто ліміту, догани перетворюються на інший тип. Наприклад, 3 усні → 1 сувора |
| Знімається імунітетом | Чи можна зняти цей тип імунітетом |

## Синхронізація з Discord { #sync }

<div class="af-steps" markdown>

1. Виберіть **канал-форум** і мітку.
2. Впишіть **назву теми** та **правила**.
3. Виберіть **ролі перевіряльників**.
4. **«Опублікувати тему»** — бот створить тему з кнопкою «Подати заяву».
5. Після правок — **«Оновити тему»**. Перемикач вмикає й вимикає приймання.

</div>

Як працюють заяви — [Зняття доган](../work/appeals.md).

## Якщо не працює { #troubleshooting }

| Повідомлення | Причина | Рішення |
|---|---|---|
| «Заповніть форум, назву теми та текст правил» | Порожні поля | Заповніть |
| «Форум не знайдено або бот не має до нього доступу» | Закритий для бота | Відкрийте боту доступ |
| «Вибраний канал не є форумом» | Звичайний канал | Створіть у Discord канал типу «Форум» |
| «Потрібне право на налаштування сервера» | Немає права | «Доступ до налаштувань» |
| «Тему створено заново в новому форумі. Стару приберіть вручну» | Змінили форум | Видаліть стару тему в Discord |
| «Синхронізацію вимкнено. Тему в Discord закрити не вдалося» | Немає доступу бота | Закрийте тему вручну |
| «Не вдалося синхронізувати догани з Discord» | Збій | Повторіть |
