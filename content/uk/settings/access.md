# Права та доступ

<p class="af-lead" markdown>Кожен бачить лише те, що йому потрібно: рядовим — просте меню, керівництву — потрібні кнопки. Усе налаштовується галочками.</p>

!!! abstract "Коротко"
    - **Де:** Налаштування сайту → Права.
    - **Три рівні:** повний доступ → видимість розділів → права на дії.

!!! tip "Назви у вас можуть відрізнятися"
    Адміністрація сервера може перейменувати розділи й слова під себе: «фракція» → «відділ», «коїни» → «бали». У документації — стандартні назви. Як це налаштовується — [Пресети та назви](presets.md).

## 1. Повний доступ

Власник сервера й адміністрація платформи бачать і можуть усе.

## 2. Видимість розділів

Для кожного пункту меню: увімкнений чи прихований, яким посадам і підрозділам видно, своя назва.

**Порожній список = видно всім.** «Налаштування сайту» вимкнути не можна, але можна обмежити.

## 3. Права на дії

Позначте галочкою дію для посади — у неї з'явиться кнопка.

| Група | Право | Що дозволяє |
|---|---|---|
| Керівництво | Суворі | Видавати й знімати суворі догани |
| | Усні | Видавати й знімати усні |
| | Міністерські | Видавати й знімати міністерські |
| | Імунітет | Видавати й знімати імунітет |
| | Коїни | Нараховувати й списувати коїни |
| | Реєстрація | Додавати учасників |
| | Видалення | Знімати учасників |
| | Дані | Редагувати нік, контакти |
| | Фракція/посада | Змінювати підрозділ і посаду |
| | Термін | Змінювати термін посади |
| | ЧС: подання | Подавати в чорний список |
| | ЧС: рішення | Схвалювати й відхиляти чорний список |
| | Звіти | Схвалювати й відхиляти звіти |
| Адміністрація | Реєстрація | Додавати керівництво |
| | Зняття | Знімати керівництво |
| | Посада адміна | Змінювати посаду керівництву |
| Discord | Форми | Налаштовувати [Форми Discord](../discord/discord-forms.md) |
| | Вебхуки | [Надсилати повідомлення від бота](../discord/webhooks.md) |
| Співбесіда | Співбесіда | Доступ до обдзвонів і результатів |
| | Видалення обдзвонів | Видаляти обдзвони |
| Налаштування сервера | Доступ до налаштувань | Відкривати й змінювати налаштування |
| Документи | Створення / Зміна / Видалення | Робота з [документами](../work/documents.md) |
| Форми | Форми | Створювати [форми](../work/forms.md) й читати відповіді |

Ті самі права перевіряє бот.

**Аудит прав** — у профілі людини можна подивитися, що саме їй дозволено.

## Якщо не працює { #troubleshooting }

| Ситуація | Причина | Рішення |
|---|---|---|
| Зник розділ меню | Видимість: у списку немає вашої посади | Додайте посаду у видимість пункту |
| «Доступ до цієї сторінки обмежено налаштуваннями сайту» | Те саме | Те саме |
| Розділ видно, кнопки немає | Немає права на дію | Позначте право для посади |
| «Недостатньо прав для цієї дії» | Те саме | Те саме |
| Кнопка є, але «Посада стоїть вище за вашу» | Людина старша | Див. [Старшинство](hierarchy.md) |
| «Не можна видати роль вищу за власну» | Спроба призначити вище себе | Призначає хтось старший |
| Права зникли після перейменування посади | Не погодилися на перенесення | Див. [Структура](structure.md#troubleshooting) |
| Права змінили, а в людини по-старому | Права оновлюються протягом ~10 секунд | Людині — оновити сторінку |

Не знаєте, чому недоступно? Запитайте [A-Faction AI](../help/ai.md) — він бачить ваші права.
