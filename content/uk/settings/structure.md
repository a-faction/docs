# Структура

<p class="af-lead" markdown>Фундамент вашого сервера: відділи, посади й ролі в Discord. З неї все починається — без структури нікого реєструвати.</p>

!!! abstract "Коротко"
    - **Де:** Налаштування сайту → Структура.
    - **Дві гілки:** адміністрація та звичайні учасники.

## Що налаштовується

| Що | Навіщо |
|---|---|
| **Міністерства / групи** | Об'єднують підрозділи |
| **Організації / підрозділи** | Фракції, відділи. Назви — з [термінів](presets.md) |
| **Типи посад** | Лідер, заступник, старший склад тощо |
| **Посади** | Назва, термін, **роль Discord** — бот видасть її під час реєстрації |
| **Канал сповіщень організації** | Повідомлення про її людей ідуть туди, а не в загальний канал |
| **Причини реєстрації** | Список причин в анкеті реєстрації |

## Порядок = старшинство

Хто вище в списку — той старший. Порядок змінюється перетягуванням. Див. [Старшинство](hierarchy.md).

## Перейменування

Під час збереження панель запитає, чи перенести учасників зі старою назвою на нову — погоджуйтеся. Інакше люди втратять права, бо права видаються за назвами. Працює і для посад, і для підрозділів.

## Якщо не працює { #troubleshooting }

| Що бачите | Чому | Що зробити |
|---|---|---|
| «Такий тип посади вже існує» / «Така причина вже існує» | Дубль | Використайте наявний |
| Не можна видалити посаду | У ній є люди | Переведіть або зніміть їх |
| «Не вдалося перенести учасників» | Збій під час перейменування | Повторіть збереження |
| Роль не видається під час реєстрації | Роль не прив'язана або бот нижче | Прив'яжіть роль, [підніміть роль бота](../start/connect-bot.md#troubleshooting) |
| Люди втратили доступ після перейменування | Відмовилися від перенесення | Поверніть стару назву або перепризначте людей |
