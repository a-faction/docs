# Налаштування планувальника

<p class="af-lead" markdown>Підлаштуйте планувальник під свій ритм: години, довжину слотів і те, що відбувається після натискання.</p>

!!! abstract "Коротко"
    - **Де:** Налаштування сайту → Планувальник.
    - **Час:** UTC+3 для всіх.

| Налаштування | Що задає |
|---|---|
| Початок і кінець дня | Години сітки |
| Крок | Довжина слота |
| Блокування сусідніх слотів | Скільки хвилин навколо зайнятого слота закрито |
| Минулий час | Чи можна займати минулий |
| Дія після натискання | Зайняти одразу чи відкрити вікно підтвердження |
| Що вказувати | Підрозділ, посада або нік у слоті |
| Текст вікна | Що написано в підтвердженні |

Як користуватися — [Планувальник](../work/planner.md).

## Якщо не працює { #troubleshooting }

| Що бачите | Чому | Що зробити |
|---|---|---|
| У людей «У налаштуваннях не вибрано, що вказувати» | Порожнє поле «Що вказувати» | Виберіть хоча б одне |
| Немає розділу в учасників | Розділ приховано | [Права](access.md) → видимість |
