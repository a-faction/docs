# Таблиця учасників

<p class="af-lead" markdown>Вирішіть, що керівництво бачить у списку складу: які колонки потрібні, як вони називаються і в якому порядку йдуть.</p>

!!! abstract "Коротко"
    - **Де:** Налаштування сайту → Таблиця.

- Перемикач — увімкнути чи вимкнути колонку.
- **«Перейменувати»** — своя назва колонки.
- Перетягування — порядок.

За замовчуванням: нік, Discord ID, підрозділ, догани. Попередження, міністерські та імунітет завжди всередині колонки «Догани».

Щільність рядків кожен вибирає собі сам — [особисті налаштування](../account/settings.md).

## Якщо не працює { #troubleshooting }

| Що бачите | Чому | Що зробити |
|---|---|---|
| «Немає увімкнених колонок» | Усі вимкнено | Увімкніть хоча б одну |
| Немає потрібної колонки | Вимкнена | Увімкніть |
| Зміни не видно | Не зберегли | «Зберегти зміни» внизу |
