# Особисті налаштування

<p class="af-lead" markdown>Зробіть панель своєю: тема, мова, щільність таблиць. Вибір зберігається в акаунті й їде з вами на будь-який пристрій.</p>

## Профіль

Discord ID, вік, соцмережі (ВКонтакте, Telegram, форум), аватар (можна GIF) і фон. Зберігається кнопкою.

## Зовнішній вигляд

| Налаштування | Варіанти |
|---|---|
| Тема | Темна, Світла, М'ятна, Опівнічна. Ще 6 — із [Premium](premium.md) |
| Мова | Русский, українська, English. Під час першого входу — мова системи |
| Оформлення | Нове або класичне |
| Щільність | Щільність рядків таблиць |
| Premium | Оформлення ніка, аватара, профілю |

Зберігається одразу, кнопки немає. Вибір зберігається в акаунті — однаковий на всіх пристроях. На інших не впливає.

## Конфіденційність

Див. [Приватність](privacy.md). Зберігається кнопкою.

## Якщо не працює { #troubleshooting }

| Що бачите | Чому | Що зробити |
|---|---|---|
| «Не збереглося» | Збій або немає зв'язку | Повторіть |
| «Будь ласка, виберіть файл зображення» | Не картинка | Виберіть PNG, JPG або GIF |
| «Помилка під час завантаження зображення» | Бите посилання або файл | Спробуйте інший файл |
| Тема Premium недоступна | Немає Premium | Див. [Premium](premium.md) |
