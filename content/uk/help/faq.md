# Часті питання

<p class="af-lead" markdown>Короткі відповіді на те, що питають найчастіше. Натисніть на питання, щоб розгорнути відповідь.</p>

## Підключення

??? question "Як підключити сервер?"
    a-faction.xyz → «Підключити сервер», 4 кроки, близько 2 хвилин. [Докладно](../start/connect-server.md).

??? question "Не приходить код"
    Зайдіть на [Discord A-Faction](https://discord.gg/2cMBp8gjYn), дозвольте особисті повідомлення від учасників серверів, надішліть код ще раз.

??? question "Де взяти ID сервера?"
    Discord → Налаштування → Розширені → «Режим розробника». Правою кнопкою по серверу → «Копіювати ID сервера».

??? question "Скільки коштує?"
    Безкоштовно. Платний лише [Premium](../account/premium.md) — оформлення.

??? question "Можна володіти кількома серверами?"
    Ні, одна людина — один сервер. Бути можна в кількох.

??? question "Як перенести налаштування з іншого сервера?"
    Пресети → Налаштування → вивантажити й застосувати. [Докладно](../settings/presets.md).

??? question "Як передати, заморозити чи видалити сервер?"
    Через [підтримку](support.md) — це робить адміністрація платформи.

## Вхід і доступ

??? question "Чому не пускає?"
    Вас немає в складі, сервер не прив'язаний або акаунт заблокований. [Докладно](../start/login.md#troubleshooting).

??? question "Зник розділ"
    Його приховали для вашої посади. [Права](../settings/access.md).

??? question "Розділ бачу, кнопки немає"
    Немає права на дію або людина старша за вас.

??? question "Заблокувало після звичайних дій"
    Оновіть сторінку й напишіть у [підтримку](support.md) — знімуть вручну.

??? question "Заходив з чужого комп'ютера"
    «Сесії» → завершіть той вхід.

??? question "Є двоетапна перевірка?"
    Власної немає — увімкніть її в Discord.

## Discord

??? question "Бот не видає ролі"
    Роль бота має бути вище за ті, що видаються. [Докладно](../start/connect-bot.md#troubleshooting).

??? question "Замість назви ролі — номер"
    Бот не бачить роль або канал.

??? question "Дія пройшла, у Discord порожньо"
    Discord або бот були недоступні, або не вибрано канал. Дані не губляться.

??? question "Чому бот пише російською?"
    Бот поки відповідає лише російською. Панель доступна українською.

## Робота

??? question "Цифри в профілі не збігаються"
    Перевірте вкладку сервера в профілі — дані по серверах окремі.

??? question "Звіт чи неактив?"
    Звіт — виконана робота, за неї коїни. Неактив — погоджена відсутність.

??? question "Чому час інший?"
    Панель працює за UTC+3 для всіх.

??? question "Можна виправити запис журналу?"
    Ні — журнал незмінний.

??? question "Як довго зберігаються записи співбесід?"
    14 днів.

## Чого немає

??? question "Голосування"
    Немає — використовуйте [Форми](../work/forms.md).

??? question "Вивантаження в Excel"
    Окремого немає. Відповіді форм — CSV (відкривається в Excel), склад — [Експорт](../work/export.md).

??? question "Видалення свого акаунта"
    Кнопки немає — через [підтримку](support.md).

??? question "Окремий застосунок для телефона"
    Немає — додайте сайт на головний екран через меню браузера.
