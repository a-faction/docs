# Усі помилки та рішення

<p class="af-lead" markdown>Побачили незрозуміле повідомлення? Знайдіть його тут — поруч буде просте пояснення й що зробити. Найшвидше — ++ctrl+f++.</p>

## Спершу спробуйте

<div class="af-steps" markdown>

1. **Оновіть сторінку.** Вкладка, що довго була відкрита, — часта причина дивних відмов.
2. **Перевірте [статус](status.md).** Якщо там збій — ми вже лагодимо.
3. **Перевірте сервер** у шапці: чи той відкрито.
4. **Запитайте [A-Faction AI](ai.md)** — він бачить ваші права.
5. **Напишіть у [підтримку](support.md).**

</div>

## Вхід

| Повідомлення | Рішення |
|---|---|
| «Доступ заборонено» / «У вас немає доступу до цієї системи» | Вас немає в складі — попросіть керівництво зареєструвати вас |
| «Вас немає на жодному сервері» | Попросіть повернути вас або [підключіть свій сервер](../start/connect-server.md) |
| «Ви скасували авторизацію в Discord» | Увійдіть знову й натисніть «Авторизувати» |
| «Сесія авторизації минула» | Натисніть «Увійти через Discord» знову |
| «Сервер перевантажений» | Повторіть за кілька секунд |
| «Внутрішня помилка сервера» + код | Спробуйте пізніше, повідомте код у підтримку |
| Постійно викидає | Дозвольте браузеру зберігати дані crm.a-faction.xyz |

Докладно — [Вхід і пристрої](../start/login.md#troubleshooting).

## Блокування { #blocked }

| Повідомлення | Що означає | Рішення |
|---|---|---|
| «Акаунт заблоковано» + «підозрілі операції… автоматично заблоковано» | Спрацював захист. Часто хибно — через стару вкладку | Оновіть сторінку й напишіть у [підтримку](support.md). Знімають вручну |
| «Для вашого профілю ввімкнено блокування доступу» | Блокування адміністрацією платформи | [Підтримка](support.md) |
| «Сервер заморожено» | Сервер призупинено | [Підтримка](support.md) |

|---|---|
| «Доступ обмежено… обмежено налаштуваннями сайту» | Розділ приховано для вашої посади — [Права](../settings/access.md) |
| «Недостатньо прав для цієї дії» | Немає права на дію — [Права](../settings/access.md) |

| «Цю дію не можна застосувати до себе» | Попросіть іншого керівника |
| «Ця дія недоступна» / «Цей розділ недоступний» | Розділ вимкнено на сервері |
| «Ці позначки собі змінювати не можна» | Досягнення й Premium видає лише адміністрація платформи |
| «Змінювати посади цією дією не можна» | Використайте «Змінити підрозділ/посаду» в профілі |
| «Запис належить іншому серверу» / «…іншій організації» | Перемкніть сервер, оновіть сторінку |
| «Сервер не обрано» | Виберіть сервер у шапці або оновіть сторінку |
| «У вас немає доступу до жодного сервера» | Попросіть керівництво зареєструвати вас |
| «Не вдалося перевірити права. Спробуйте за хвилину» | Тимчасовий збій — зачекайте |

## Збереження

| Повідомлення | Рішення |
|---|---|
| «Не вдалося виконати дію» / «Помилка на сервері» | Повторіть. Повторюється — підтримка |
| «Такий запис уже є» | Дубль — використайте наявний |
| «Забагато змін за один раз» | Розбийте на частини |
| «Це поле змінювати не можна» / «Запит зібрано неправильно» / «Запит містить невідоме поле» | Оновіть сторінку — у вас стара версія панелі |
| «Обережно — є незбережені зміни!» | Натисніть «Зберегти зміни» |

| «Бота немає на цьому Discord-сервері» | [Додайте бота](../start/connect-bot.md) |

## Зв'язок і збої

| Повідомлення | Рішення |
|---|---|
| «Немає з'єднання» | Перевірте інтернет — панель підключиться сама |
| «Сайт недоступний» | Зачекайте хвилину. Не допомагає — VPN, [статус](status.md) |
| «Технічні роботи» | Натисніть «Перевірити знову» пізніше |
| Смуга «Виявлено збій у роботі сервісів» | Нічого робити не треба, лагодимо |
| Білий екран | Оновіть сторінку (++ctrl+shift+r++), очистіть кеш, спробуйте інший браузер |

## Час

Панель працює за **UTC+3** — однаково для всіх. Якщо час у планувальнику чи журналі відрізняється від вашого, це різниця часових поясів.
