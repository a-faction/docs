# Словник

<p class="af-lead" markdown>Простими словами — про слова, що трапляються в панелі та в цій документації.</p>

Панель (CRM)
:   Сайт [crm.a-faction.xyz](https://crm.a-faction.xyz), де команда веде роботу.

Сервер
:   Ваша спільнота в A-Faction. Зазвичай = один Discord-сервер.

Discord ID
:   Постійний номер акаунта, сервера, ролі чи каналу в Discord, 17–20 цифр. Нік змінюється, ID — ні.

Режим розробника
:   Налаштування Discord, яке дозволяє копіювати ID: Налаштування → Розширені.

Бот
:   Програма на вашому Discord-сервері, виконує команди від імені A-Faction.

Команда бота
:   Повідомлення, що починається з `/`, наприклад `/user`.

Підрозділ
:   Фракція, відділ, організація. Назва залежить від сервера.

Міністерство / група
:   Об'єднання кількох підрозділів.

Посада
:   Становище людини в підрозділі. Від неї залежать права й роль у Discord.

Старшинство
:   Хто ким може керувати. Задається порядком посад.

Права
:   Що людина бачить і може робити в панелі.

Власник сервера
:   Той, хто підключив сервер. Може все на своєму сервері.

Адміністрація платформи
:   Команда A-Faction: підтримка, блокування, передача й видалення серверів.

Догана (стягнення)
:   Покарання: усна, сувора, міністерська, попередження.

Ескалація
:   Автоматичне посилення доган, коли досягнуто ліміту.

Імунітет
:   Захист, яким можна зняти догану.

Неактив
:   Погоджена відсутність.

Коїни
:   Внутрішня валюта. Може називатися інакше.

Обдзвін
:   Співбесіда з кандидатами.

Слот
:   Відрізок часу в планувальнику.

Журнал (логи)
:   Незмінний список усіх дій.

Архів
:   Люди, зняті з посади, з історією.

Сесія
:   Вхід із конкретного пристрою.

Вебхук
:   Повідомлення в Discord від імені бота.

Картка
:   Оформлене повідомлення Discord: кольорова смуга, заголовок, поля.

Форум
:   Тип каналу Discord, де кожне обговорення — окрема тема.

Гілка
:   Окреме обговорення всередині каналу чи форуму Discord.

Пресет
:   Готовий набір налаштувань або назв.

Автоматизація
:   Правило «якщо — то», спрацьовує саме.

UTC+3
:   Часовий пояс, за яким працює панель.

Premium
:   Платне оформлення профілю.
