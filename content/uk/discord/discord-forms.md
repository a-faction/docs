# Форми Discord

<p class="af-lead" markdown>Навчіть бота працювати на вас: кнопки для заявок, автовідповіді, випадні меню й видача ролей однією командою.</p>

!!! abstract "Коротко"
    - **Де:** бічне меню → «Форми Discord».
    - **Право:** «Форми» в групі «Discord» (Налаштування команд і форм).

## Види правил

| Вид | Що робить |
|---|---|
| **Форма** | Повідомлення з кнопками. Учасник подає заявку, бот надсилає картку з кнопками «Схвалити» / «Відмовити» |
| **Команда** | Показує список людей із роллю або видає/знімає роль командами `/a_назва`, `/d_назва` |
| **Відповідь** | Бот відповідає заготовленим текстом |
| **Селектор** | Повідомлення з випадним меню, кожен пункт — своя відповідь |

## Створити правило

<div class="af-steps" markdown>

1. «Форми Discord» → створити → виберіть вид.
2. Назва правила (унікальна на сервері).
3. Канали та ролі з доступом — зі списку вашого Discord.
4. Оформлення картки: колір, заголовок, поля, картинка.
5. Кнопки: ID, текст, колір. «Просити причину» — бот попросить текст після натискання. «Прибирати кнопки після натискання» — за бажанням.
6. Що робити з повідомленням учасника: видалити чи закріпити. Кого згадати.
7. Збережіть — бот опублікує правило.

</div>

У тексті можна використовувати підстановки — список показано у вікні правила.

## Таблиця правил

Перемикач увімк./вимк. (вимкнене правило не реагує), пошук, фільтри, масове редагування й видалення.

## Якщо не працює { #troubleshooting }

| Що бачите | Чому | Що зробити |
|---|---|---|
| «Не можна зберегти» + список полів | Не заповнено обов'язкові поля | Заповніть перелічені |
| «Кнопки (є однакові ID)» | Повтор ID кнопки | Зробіть ID різними |
| «Правило збережено, але не вказано канал для публікації» | Немає каналу | Виберіть канал |
| «Правило збережено, але вибраний канал не є текстовим» | Голосовий канал або категорія | Виберіть текстовий |
| «Правило збережено, але канал не знайдено або бот не має доступу» | Канал закритий для бота | Відкрийте доступ боту |
| «Канал не належить вашому серверу» | Канал з іншого Discord | Виберіть свій |
| «Роль не знайдено на вашому сервері» | Роль видалено | Виберіть знову |
| Назву правила зайнято | На сервері вже є правило з такою назвою | Перейменуйте |
| Бот не видає роль за командою | Роль бота нижча | [Підніміть роль бота](../start/connect-bot.md#troubleshooting) |
| Правило не реагує | Вимкнене | Увімкніть перемикачем |
