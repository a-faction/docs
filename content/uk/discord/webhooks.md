# Повідомлення від імені бота

<p class="af-lead" markdown>Гарні оголошення від імені бота без сторонніх сервісів: зібрали повідомлення, подивилися, як воно виглядає, — надіслали.</p>

!!! abstract "Коротко"
    - **Де:** бічне меню → «Вебхуки».
    - **Право:** «Вебхуки» (Надсилання в Discord).

<div class="af-steps" markdown>

1. Виберіть канал.
2. Заповніть: текст над карткою, автор, заголовок і посилання, опис, колір, поля, мала й велика картинки, підпис унизу з датою.
3. Перевірте попередній перегляд.
4. **«Надіслати»**. **«Скинути»** — очистити.

</div>

Працює форматування Discord: жирний, курсив, посилання, згадки. Кожне надсилання — у журналі.

## Якщо не працює { #troubleshooting }

| Що бачите | Чому | Що зробити |
|---|---|---|
| Немає розділу або кнопки «Надіслати» | Немає права «Вебхуки» | [Права](../settings/access.md) |
| «Канал не знайдено» | Канал видалено або закрито для бота | Відкрийте доступ боту |
| «Канал не належить вашому серверу» | Канал з іншого Discord | Виберіть свій |
| «ID сервера не знайдено» | Сервер не прив'язаний до Discord | Перевірте [Огляд](../settings/overview.md) |
| Вебхук відхилено: помилка введення | Задовгий текст або неправильні дані | Скоротіть текст, перевірте посилання на картинки |
