# Команди бота

<p class="af-lead" markdown>Найпотрібніші дії — однією командою в чаті. Наберіть `/` у будь-якому каналі, де є бот, і виберіть потрібну.</p>

| Команда | Що робить | Потрібне право |
|---|---|---|
| `/user @учасник` | Профіль: посада, коїни, догани, соцмережі, досягнення, кнопка «Історія дій» | — |
| `/registration @учасник` | Реєстрація | «Реєстрація» (учасники або адміністрація) |
| `/reprimand @учасник` | Видати чи зняти догану | На цей тип догани |
| `/coins @учасник` | Нарахувати чи списати коїни | «Коїни» |
| `/shop @учасник` | Списати коїни за товар | «Коїни» |
| `/demote @учасник` | Зняти з посади: ролі та запис у складі | «Видалення» або «Зняття» (адміністрація) |
| `/archive @учасник` | Архів посад | — |
| `/log @учасник [з] [по]` | Журнал за період | — |
| `/faction_bug текст` | Повідомити про помилку | — |
| `/ping` | Перевірити, чи відповідає бот | — |
| `/help` | Список команд | — |
| `/xo` | Хрестики-нулики з ботом | — |

Плюс власні команди сервера з [Форм Discord](discord-forms.md): `/a_назва` і `/d_назва` (видати й зняти роль), списки ролей, автовідповіді.

## Правила

- Права ті самі, що й у панелі.
- [Старшинство](../settings/hierarchy.md) діє: над старшими — не можна.
- Якщо ви в кількох спільнотах, бот попросить вибрати сервер.
- Заблокований акаунт команди не виконує.

## Якщо не працює { #troubleshooting }

Бот відповідає російською — нижче оригінал і переклад.

| Відповідь бота | Чому | Що зробити |
|---|---|---|
| «Вы не зарегистрированы» (ви не зареєстровані) | Вас немає в складі | Пройдіть реєстрацію |
| «У вас нет прав на это действие» (немає прав на цю дію) | Немає права | [Права](../settings/access.md) |
| «У вас нет права регистрировать игроков» / «…администрацию» | Немає права «Реєстрація» | Те саме |
| «У вас нет права снимать игроков» / «…участников администрации» | Немає права «Видалення» / «Зняття» | Те саме |
| «У вас нет прав на этот тип санкции» (немає прав на цей тип санкції) | Немає права на тип догани | Те саме |
| «Нельзя применять это действие к вышестоящему участнику» (не можна застосувати до старшого) | Людина старша | Див. [Старшинство](../settings/hierarchy.md) |
| «У вас нет доступа к серверу этого игрока» (немає доступу до сервера цього гравця) | Людина на іншому сервері | — |
| «Игрок числится на нескольких серверах. Выберите…» (гравець на кількох серверах) | Потрібно вибрати сервер | Виберіть у меню |
| «Игрок не найден на этом сервере» (гравця не знайдено на цьому сервері) | Людина не в складі | Перевірте згадку |
| «Не удалось найти пользователя на Discord сервере» (не знайдено в Discord) | Людини немає на Discord-сервері | Запросіть її |
| «Выбранная должность не найдена в списке» (посаду не знайдено) | Структура змінилася | Повторіть команду |
| «Выбранный товар не найден» (товар не знайдено) | Товар видалили | Повторіть |
| «Ваш аккаунт заблокирован в A-Faction» (акаунт заблоковано) | Блокування | [Підтримка](../help/support.md) |
| «Не удалось определить сервер. Повторите команду» (не вдалося визначити сервер) | Збій вибору | Повторіть |
| Команди немає в списку | Бот не на сервері або Discord ще не оновив список | Зачекайте кілька хвилин, перезапустіть Discord |
| Бот мовчить | Бот не працює | Перевірте `/ping` і [статус](../help/status.md) |
