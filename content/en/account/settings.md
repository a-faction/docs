# Personal settings

<p class="af-lead" markdown>Make the panel yours: theme, language, table density. Your choice is stored in your account and follows you to any device.</p>

## Profile

Discord ID, age, social links (VK, Telegram, forum), avatar (GIF works) and background. Saved with a button.

## Appearance

| Setting | Options |
|---|---|
| Theme | Dark, Light, Mint, Midnight. 6 more with [Premium](premium.md) |
| Language | Русский, українська, English. On first sign-in — your system language |
| Layout | New or classic |
| Density | Table row density |
| Premium | Nickname, avatar and profile cosmetics |

Saved instantly, no button. Stored in your account — the same on every device. Doesn't affect anyone else.

## Privacy

See [Privacy](privacy.md). Saved with a button.

## Troubleshooting { #troubleshooting }

| What you see | Why | What to do |
|---|---|---|
| "Not saved" | Failure or no connection | Try again |
| "Please choose an image file" | Not an image | Pick a PNG, JPG or GIF |
| "Error while uploading the image" | Broken link or file | Try another file |
| A Premium theme is locked | No Premium | See [Premium](premium.md) |
