# Glossary

<p class="af-lead" markdown>Plain-language explanations of words you'll meet in the panel and in these docs.</p>

Panel (CRM)
:   The site [crm.a-faction.xyz](https://crm.a-faction.xyz) where the team works.

Server
:   Your community in A-Faction. Usually = one Discord server.

Discord ID
:   A permanent 17–20 digit number for an account, server, role or channel. Nicknames change; IDs don't.

Developer Mode
:   A Discord setting that lets you copy IDs: Settings → Advanced.

Bot
:   A program on your Discord server that runs commands for A-Faction.

Bot command
:   A message starting with `/`, e.g. `/user`.

Unit
:   A faction, department or organization. The name depends on the server.

Group
:   A section heading in the member table. Holds several factions. Used to be called a “ministry”.

Position
:   A person's place in a unit. It decides permissions and the Discord role.

Rank order
:   Who can manage whom. Set by the order of positions.

Permissions
:   What a person can see and do in the panel.

Server owner
:   Whoever connected the server. Can do everything on it.

Platform admins
:   The A-Faction team: support, blocks, server transfers and deletion.

Reprimand
:   A penalty: verbal, strict, ministry, warning.

Escalation
:   Reprimands upgrading automatically when a limit is hit.

Immunity
:   Protection that can be spent to remove a reprimand.

Leave
:   Agreed time off.

Coins
:   The internal currency. May have another name.

Interview
:   Questioning candidates, usually in a voice channel.

Slot
:   A time block in the planner.

Log
:   The immutable list of all actions.

Archive
:   People removed from positions, with their history.

Session
:   A sign-in on a particular device.

Webhook
:   A Discord message sent as the bot.

Card
:   A formatted Discord message: colour bar, title, fields.

Forum
:   A Discord channel type where each discussion is its own post.

Thread
:   A separate discussion inside a Discord channel or forum.

Preset
:   A ready-made bundle of settings or wording.

Automation
:   An "if — then" rule that runs on its own.

UTC+3
:   The time zone the panel runs on.

Premium
:   Paid profile cosmetics.
