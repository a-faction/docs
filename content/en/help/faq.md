# FAQ

<p class="af-lead" markdown>Short answers to the most common questions. Click a question to expand it.</p>

## Connecting

??? question "How do I connect a server?"
    a-faction.xyz → "Connect a server", 4 steps, about 2 minutes. [Details](../start/connect-server.md).

??? question "The code doesn't arrive"
    Join the [A-Faction Discord](https://discord.gg/2cMBp8gjYn), allow DMs from server members, send the code again.

??? question "Where do I get the server ID?"
    Discord → Settings → Advanced → "Developer Mode". Right-click the server → "Copy Server ID".

??? question "How much does it cost?"
    Free. Only [Premium](../account/premium.md) — cosmetics — is paid.

??? question "Can I own several servers?"
    No, one person — one server. You can be a member of several.

??? question "How do I copy settings from another server?"
    Presets → Settings → export and apply. [Details](../settings/presets.md).

??? question "How do I transfer, freeze or delete a server?"
    Through [support](support.md) — the platform admins do it.

## Sign-in and access

??? question "Why can't I get in?"
    You're not on a roster, the server isn't linked, or the account is blocked. [Details](../start/login.md#troubleshooting).

??? question "A section disappeared"
    It was hidden for your position. [Permissions](../settings/access.md).

??? question "I see the section but not the button"
    No permission for the action, or the person outranks you.

??? question "I got blocked after normal actions"
    Refresh and contact [support](support.md) — it's lifted manually.

??? question "I signed in on someone else's computer"
    "Sessions" → end that session.

??? question "Is there two-step verification?"
    Not our own — turn it on in Discord.

## Discord

??? question "The bot doesn't give roles"
    The bot's role must be above the roles it assigns. [Details](../start/connect-bot.md#troubleshooting).

??? question "A number instead of a role name"
    The bot can't see the role or channel.

??? question "The action worked but nothing came to Discord"
    Discord or the bot was down, or no channel is set. No data is lost.

??? question "Why does the bot reply in Russian?"
    For now the bot replies only in Russian. The panel is available in English.

## Work

??? question "Profile numbers don't add up"
    Check the server tab in the profile — data is kept per server.

??? question "Report or leave?"
    A report is work done and earns coins. A leave is agreed time off.

??? question "Why is the time different?"
    The panel runs on UTC+3 for everyone.

??? question "Can I fix a log entry?"
    No — the log is immutable.

??? question "How long are interview recordings kept?"
    14 days.

## Not available

??? question "Polls"
    None — use [Forms](../work/forms.md).

??? question "Excel export"
    No dedicated one. Form answers export as CSV (opens in Excel); the roster via [Export](../work/export.md).

??? question "Deleting my account"
    No button — go through [support](support.md).

??? question "A phone app"
    None — add the site to your home screen from the browser menu.
