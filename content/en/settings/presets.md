# Presets and terms

<p class="af-lead" markdown>Your own words and ready-made bundles: turn "factions" into "departments", and copy one server's setup to another in a couple of clicks.</p>

!!! abstract "In short"
    - **Where:** Site settings → Presets.

## Terms

Change only the labels across the panel: "faction" → "department", "coins" → "points". Singular and plural are set separately.

Ready-made sets: game faction, guild, esports team, moderation team, volunteer team. Any word can be edited by hand. Data and permissions don't change.

## Settings

A whole bundle: structure, permissions, reprimands, planner and other sections.

- **Export** your server's settings to a file.
- **Apply** a ready-made bundle or a file. Dots show the changed sections. Nothing is written until you press "Save".

!!! info "Never transferred"
    The Discord link, channels, webhooks and secrets.

## Troubleshooting { #troubleshooting }

| Message | Cause | Fix |
|---|---|---|
| "The file does not look like a settings template" | Wrong file | Pick a file exported from A-Faction |
| "Template version …, supported version is …" | Old format | Export again |
| "The template has no portable settings at all" | Empty file | Export again |
| Channels are empty after applying | Channels aren't transferred | Pick channels manually |
