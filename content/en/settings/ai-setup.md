# Setup in plain words

<p class="af-lead" markdown>Just write what to change — "add a department", "rename a position" — and the AI prepares the changes and shows them before saving.</p>

!!! abstract "In short"
    - **Where:** Site settings → Help → AI assistant.
    - **Who:** "Settings access".

## Examples

- "Add the FBI organization to Government"
- "Rename the Deputy position to Vice leader"
- "Turn the planner on"
- "Put Curator above Leader"
- "Add a registration reason"

## How it works

<div class="af-steps" markdown>

1. Write what to change. If it's unclear, the AI asks.
2. The AI shows a plan — each change on its own line with a tick.
3. **"Add to draft"** — the changes appear in settings but aren't saved.
4. **"Save"** at the bottom. **"Cancel"** reverts.

</div>

| Can | Can't |
|---|---|
| Add and rename units, groups, positions, reasons | Action permissions |
| Change the order (rank) | Discord roles and channels |
| Turn sections on | Terms, reprimand limits |
| Change wording (terms) | Planner times, columns, automations |

On rename, people, permissions, channels and the menu move over automatically. A unit with people in it can't be deleted.

## Troubleshooting { #troubleshooting }

| Message | Cause | Fix |
|---|---|---|
| "The AI didn't answer" | Temporary failure | Retry or change it manually |
| The organization / position "… already exists" | Duplicate | — |
| "There is no organization …" | Name typo | Use the exact name from settings |
| "… isn't in group … — moves only work inside a group" | Different groups | Reorder within one group |
| "Couldn't count members — the plan can't be applied" | Failure | Retry |
| "The new organization gets no permissions" | The AI doesn't change permissions | Assign them in [Permissions](access.md) |
| "The message is longer than N characters" | Too long | Shorten it |
