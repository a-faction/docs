# Overview

<p class="af-lead" markdown>Your server's control panel: a readiness score and a list of what's left to set up. Yellow means to do, green means done.</p>

!!! abstract "In short"
    - **Where:** Site settings → Overview.

- **Readiness %** — the share of checks passed.
- **Checklist**: Discord server linked · Leadership and administration · Positions in factions · Permission matrix filled. A yellow item has a **"Set up"** button that takes you to the right section. All green — the server is ready.
- **Quick setup** — build the structure from a description of your community. See [First setup](../start/first-steps.md).
- **General information** — the owner, the linked Discord server, its ID and connection state.

## Transfer, freeze, delete a server, change Discord

Not something you can do yourself. The platform admins do it: contact [support](../help/support.md).

## Troubleshooting { #troubleshooting }

| What you see | Why | What to do |
|---|---|---|
| "Not linked" / "no connection" | The bot isn't on the server or the link was lost | [Add the bot](../start/connect-bot.md) again |
| An item stays yellow | The section isn't complete | Click "Set up" |
