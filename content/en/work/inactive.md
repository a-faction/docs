# Leave of absence

<p class="af-lead" markdown>Going on holiday or taking a break? Log a leave so nobody wonders where you went.</p>

!!! abstract "In short"
    - **Request:** side menu → "Leaves".
    - **Review:** side menu → "Leave requests".
    - **A leave doesn't remove reprimands and doesn't pause the position term.**

## Request one

<div class="af-steps" markdown>

1. "Leaves" → pick the position.
2. Enter the reason, who agreed it, the start and end dates (the end can't be in the past).
3. Submit. Status — **"Under review"**.

</div>

## Review { #review }

"Leave requests" → a request → **approve**, **reject** or **end early**. Every decision is logged and the author is notified.

| Status | Meaning |
|---|---|
| Under review | Waiting for a decision |
| Active | Approved and running |
| Inactive | Finished, rejected or ended early |

## Where it shows

- in the profile — a badge with the end date;
- in the member table — in the person's row;
- leave days are counted when the position term is changed.

Start and end reminders — [automations](../settings/notifications.md#automations).

## Troubleshooting { #troubleshooting }

| What you see | Why | What to do |
|---|---|---|
| "Could not submit the leave" | A failure or lost connection | Try again later |
| Can't pick the end date | It's in the past | Pick a future date |
| No "Leave requests" | It's a leadership section | You need visibility — [Permissions](../settings/access.md) |
| No position in the list | You hold no position on this server | Switch server |
