# Reports

<p class="af-lead" markdown>Did the work? Report it and get rewarded. Members write formatted reports; leaders approve them and hand out coins on the spot.</p>

!!! abstract "In short"
    - **Where:** side menu → "Reports".
    - **Who submits:** any member with a position.
    - **Who reviews:** the "Reports" permission.
    - **Editing your own:** until it's reviewed.

## Submit

<div class="af-steps" markdown>

1. "Reports" → **"Submit a request"**.
2. Pick the unit and period.
3. Write the text. Toolbar: heading, bold, italic, strikethrough, lists, tasks, quote, code, link, divider. Keys: ++ctrl+b++, ++ctrl+i++, ++ctrl+k++.
4. The **"Preview"** tab shows the report the way the reviewer will see it.
5. Submit. Status — **"Pending"**.

</div>

Maximum — 20,000 characters.

## Edit

**"Edit"** on the report row or in the view window. You can change the period and the text. After a decision, editing is closed.

## Review

- **Approve** + a number of coins — given to every selected member.
- **Reject** — no coins.

The decision goes to the log and to the author's notifications.

Reminders: "report without a decision for N hours", "member hasn't reported for N days" — [automations](../settings/notifications.md#automations).

## Troubleshooting { #troubleshooting }

| What you see | Why | What to do |
|---|---|---|
| "The report is empty — write at least one item" | Empty text | Fill it in |
| "The report is too long — up to 20,000 characters" | Too long | Shorten it |
| "The start date cannot be later than the end date" | Dates swapped | Fix them |
| "Enter a real date with a four-digit year" | Invalid date | Fix it |
| "The report has already been reviewed and can't be changed" | A decision was made | Submit a new report |
| "You can only edit your own report" | Someone else's report | — |
| "… is not in the database — they may have been removed from the position" | The author was removed | Reject the report |
| The position is gone / no positions — nowhere to add coins | The position changed | Reject, or add coins manually |
| No "Approve" / "Reject" buttons | No "Reports" permission | [Permissions](../settings/access.md) |
