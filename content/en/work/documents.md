# Documents

<p class="af-lead" markdown>Charters, rules, procedures and spreadsheets in one place, with full-text search. No more digging through pinned messages.</p>

!!! abstract "In short"
    - **Where:** side menu → "Documents".
    - **Permissions:** "Creation", "Change", "Deletion" in the "Documents" group.

- Tabs **"All"**, **"Documents"**, **"Spreadsheets"**.
- Search looks inside the text, not just titles.
- A document belongs to the server where it was created.
- Spreadsheets let you add columns and rows.

!!! danger "Deletion is permanent"
    A deleted document can't be restored. You're asked to confirm once.

## Troubleshooting { #troubleshooting }

| What you see | Why | What to do |
|---|---|---|
| No create or edit button | No permission | [Permissions](../settings/access.md) |
| "Could not save the changes" | Failure or lost connection | Keep the page open and retry |
| "No documents" | Nothing created yet | — |
