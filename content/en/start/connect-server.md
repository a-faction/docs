# Connect a server

<p class="af-lead" markdown>Four steps, two minutes, and your Discord server is connected to A-Faction. Nothing to pay, no card needed.</p>

!!! abstract "In short"
    - **Where:** [a-faction.xyz](https://a-faction.xyz) → "Connect a server". The panel has no such button.
    - **You need:** a Discord account and admin rights on your Discord server.
    - **Limit:** one person can own only one server.

## Steps

<div class="af-steps" markdown>

1. **Account and server.** Enter your Discord ID or username and the Discord server ID. Click **"Get Code"**.
2. **Code from Discord.** The bot sends a 6-digit code to your direct messages — enter it.
3. **Bot on the server.** Click **"Add the bot"**, pick your server, confirm the permissions, come back and click **"Check for bot"**.
4. **Server details.** Name (filled in automatically), category, your nickname, name, age (14–80), social links if you like. Click **"Register your server"**.
5. **Sign in.** Click **"Open the CRM"** and sign in with Discord — your owner profile already exists. **"Get roles"** gives you your Discord roles.

</div>

The panel is empty after this — that's expected. Next: [first setup](first-steps.md).

## How to find an ID

A nickname can change; an ID is a permanent 17–20 digit number.

<div class="af-steps" markdown>

1. Discord → **User Settings → Advanced** → turn on **"Developer Mode"**.
2. Server ID: right-click the server in the left list → **"Copy Server ID"**.
3. Your ID: right-click your avatar → **"Copy User ID"**.

</div>

## Code rules

- Valid for **10 minutes**, works **once**.
- Can be sent up to **3 times** and entered up to **10 times** per 15 minutes.

## Troubleshooting { #troubleshooting }

| What you see | Why | What to do |
|---|---|---|
| The code doesn't arrive | The bot can only DM people it shares a server with, and only if DMs are open | Join the [A-Faction Discord server](https://discord.gg/2cMBp8gjYn), turn on **Privacy → Direct messages from server members** in Discord, click **"Send again"** |
| "Код уже отправлялся несколько раз. Подождите 15 минут" (code already sent several times, wait 15 minutes) | Send limit reached | Wait 15 minutes |
| "Код не найден. Запросите новый" / "Код уже был использован" (code not found / already used) | The code expired (10 minutes) or was already entered | Request a new code |
| Step 3 can't find the bot | The bot was added to another server or the invite wasn't confirmed | Click "Add the bot" again and pick the server whose ID you entered |
| "This Discord server is already registered" | The server is already connected | If it's yours, contact [support](../help/support.md) |
| "This Discord account is already registered as a server owner" | You can own only one server | Use your existing one or contact support |
| "Registration stopped" | One of the steps failed | Try again. Still failing — [support](../help/support.md) |
