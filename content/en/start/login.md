# Sign-in and devices

<p class="af-lead" markdown>No passwords: you sign in to A-Faction with your Discord account. Sign in once and the panel remembers you for a long time.</p>

!!! abstract "In short"
    - **Where:** [crm.a-faction.xyz](https://crm.a-faction.xyz) → **"Sign in with Discord"**.
    - **How long you stay signed in:** a long time — no need to sign in daily.
    - **All sign-ins:** the "Sessions" section.

## How to sign in

<div class="af-steps" markdown>

1. Open [crm.a-faction.xyz](https://crm.a-faction.xyz) and click **"Sign in with Discord"**.
2. In Discord click **"Authorize"**.
3. You're back in the panel.

</div>

Only people who are on at least one server's roster can sign in. No server of your own — you need [registration](../work/members.md#register) or to [connect your own](connect-server.md).

!!! tip "Protect your Discord"
    The panel has no two-step verification of its own — Discord provides it. Turn it on in Discord: **Settings → My Account → Two-Factor Authentication**.

## Sessions { #sessions }

The **"Sessions"** section lists every device you're signed in on: device, address, sign-in time and last activity.

- end one session — the button on its row;
- **"Sign out"** — on this device;
- **"Sign out everywhere"** — on all devices.

!!! warning "Signed in on someone else's computer?"
    Closing the tab isn't enough — end that session in "Sessions".

## Several servers

The server switcher is in the header. Each server has its own data, permissions and names, so the panel may look different after switching.

## Troubleshooting { #troubleshooting }

| What you see | Why | What to do |
|---|---|---|
| "Access denied. You do not have access to this system" | Your Discord account isn't on any server's roster | Ask the leadership to register you |
| "You are not on any server" | You were removed from every server | Ask to be added back or [connect your own server](connect-server.md) |
| "You cancelled the Discord authorisation" | You clicked "Cancel" in Discord | Sign in again and click "Authorize" |
| "Sign-in session expired" | The sign-in window was open too long | Click "Sign in with Discord" again |
| "Discord did not return an authorisation code" / "Could not get a token from Discord" / "Could not load your Discord profile" | Connection problem with Discord | Try again in a minute. Check the [status](../help/status.md) |
| "Server is busy" | Temporary overload | Retry in a few seconds |
| "Internal server error" with a code | Our side failed | Try later. Still failing — contact [support](../help/support.md) with the code |
| "The account is blocked" | Blocked by protection or by admins | See [Blocked](../help/troubleshooting.md#blocked) |
| "The server is frozen" | The platform admins suspended the server | Contact [support](../help/support.md) |
| "This server is not available to you" / "Could not switch the server" | You were removed from that server or the connection dropped | Refresh the page |
| "No sessions found" | Your sign-in is out of date | Refresh or sign in again |
| You keep getting signed out | The browser clears site data or blocks third-party data | Allow crm.a-faction.xyz to store data and turn off "clear on exit" |
