# Документация A-Faction

Публичная документация для пользователей — `docs.a-faction.xyz`. Статический сайт на
[MkDocs Material](https://squidfunk.github.io/mkdocs-material/), отдаётся Caddy.

## Устройство

- `config/base.yml` — общее для всех языков: тема, расширения, переключатель языков.
- `mkdocs.yml` (ru, корень `/`), `mkdocs.uk.yml` (`/uk/`), `mkdocs.en.yml` (`/en/`) — язык, палитра, меню.
- `content/{ru,uk,en}/` — страницы. **Имена файлов и якоря (`{ #troubleshooting }`) одинаковые во всех
  языках** — на этом держится переключатель языка, который ведёт на ту же страницу.
- `theme/assets/` — стили (`css/af.css`), шрифт лендинга, логотип, скрипт переключателя языка.

Новая страница = файл в трёх `content/<язык>/` + строка в `nav` трёх конфигов.

## Как писать

- Для обычных людей: без технических слов, без обращений к разработчикам.
- Шаблон статьи: короткое вступление → блок «Коротко» (где, кто может) → шаги → таблица «Если не работает»
  с настоящими текстами ошибок.
- Тексты ошибок берутся из `crm/src/locales/*.json` и бота (`ds-bot-go`, только по-русски — в en/uk
  оригинал + перевод в скобках).
- Факты — из справочника ИИ (`backend-go/internal/ai/knowledge.go`). Новая функция → обновить и его, и документацию.
- Время панели пишем как UTC+3, без упоминания города.

## Локально

```bash
docker run --rm -it -p 8000:8000 -v "$PWD":/docs squidfunk/mkdocs-material:9.6.14 serve -a 0.0.0.0:8000 -f mkdocs.yml
# другой язык: -f mkdocs.uk.yml / -f mkdocs.en.yml
```

## Сборка

```bash
docker build -t a-faction-docs . && docker run --rm -p 3007:3007 a-faction-docs
```

Сборка идёт с `--strict` и проверкой якорей: битая ссылка роняет сборку. Порт — `PORT` (по умолчанию 3007).
