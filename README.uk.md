# Документація A-Faction

[English](README.md) · [Русский](README.ru.md) · **Українська**

Публічний посібник користувача [A-Faction](https://a-faction.xyz) — панелі керування та Discord-бота для спільнот.

**Читати на [docs.a-faction.xyz](https://docs.a-faction.xyz/uk/)** — українською, [російською](https://docs.a-faction.xyz) та [англійською](https://docs.a-faction.xyz/en/).

На сайті описано кожен розділ панелі та бота: як підключити сервер, налаштувати права, працювати зі складом і що робити, якщо щось пішло не так. Наприкінці кожної статті — таблиця «Якщо не працює» зі справжніми повідомленнями панелі та бота.

## Що всередині

| Шлях | Що там |
|---|---|
| `content/ru`, `content/uk`, `content/en` | Статті в Markdown, по теці на мову |
| `mkdocs.yml`, `mkdocs.uk.yml`, `mkdocs.en.yml` | Налаштування сайту й меню для кожної мови |
| `config/base.yml` | Спільні налаштування для всіх мов |
| `theme/assets` | Стилі, шрифт, логотип і перемикач мови |
| `Dockerfile`, `Caddyfile` | Збирання та роздача сайту |

Сайт збирається на [MkDocs Material](https://squidfunk.github.io/mkdocs-material/).

## Переглянути в себе

Потрібен лише Docker.

```bash
docker run --rm -it -p 8000:8000 -v "$PWD":/docs squidfunk/mkdocs-material:9.6.14 serve -a 0.0.0.0:8000 -f mkdocs.uk.yml
```

Відкрийте http://localhost:8000. Правки видно одразу. Для іншої мови замініть кінець на `-f mkdocs.yml` (російська) або `-f mkdocs.en.yml`.

## Зібрати сайт повністю

```bash
docker build -t a-faction-docs .
docker run --rm -p 3007:3007 a-faction-docs
```

Відкрийте http://localhost:3007/uk/. Збирання зупиняється на будь-якому битому посиланні чи якорі, тож якщо воно пройшло — посилання в порядку. Порт змінюється змінною `PORT`.

## Як запропонувати правку

1. Виправте статтю в **усіх трьох** мовних теках. Ім'я файлу в усіх мовах однакове — на цьому тримається перемикач мови.
2. Новій статті потрібен рядок у розділі `nav` усіх трьох файлів `mkdocs*.yml`.
3. Перевірте результат у себе й відкрийте pull request.

### Як пишуться статті

- Для звичайних людей: без технічних слів і без звертань до розробників.
- Усі статті влаштовані однаково: короткий вступ, блок «Коротко» (де знайти, кому доступно), кроки й таблиця «Якщо не працює»: що бачите, чому, що зробити.
- Повідомлення про помилки наводяться дослівно, як їх показує панель. Discord-бот відповідає лише російською, тому в українських та англійських статтях його повідомлення подано в оригіналі з перекладом у дужках.
- Час панелі вказується як UTC+3.
