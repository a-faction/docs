# Документация A-Faction

[English](README.md) · **Русский** · [Українська](README.uk.md)

Публичное руководство пользователя [A-Faction](https://a-faction.xyz) — панели управления и Discord-бота для сообществ.

**Читать на [docs.a-faction.xyz](https://docs.a-faction.xyz)** — на русском, [украинском](https://docs.a-faction.xyz/uk/) и [английском](https://docs.a-faction.xyz/en/).

На сайте описан каждый раздел панели и бота: как подключить сервер, настроить права, работать с составом и что делать, если что-то пошло не так. В конце каждой статьи — таблица «Если не работает» с настоящими сообщениями панели и бота.

## Что внутри

| Путь | Что там |
|---|---|
| `content/ru`, `content/uk`, `content/en` | Статьи в Markdown, по папке на язык |
| `mkdocs.yml`, `mkdocs.uk.yml`, `mkdocs.en.yml` | Настройки сайта и меню для каждого языка |
| `config/base.yml` | Общие настройки для всех языков |
| `theme/assets` | Стили, шрифт, логотип и переключатель языка |
| `Dockerfile`, `Caddyfile` | Сборка и раздача сайта |

Сайт собирается на [MkDocs Material](https://squidfunk.github.io/mkdocs-material/).

## Посмотреть у себя

Нужен только Docker.

```bash
docker run --rm -it -p 8000:8000 -v "$PWD":/docs squidfunk/mkdocs-material:9.6.14 serve -a 0.0.0.0:8000
```

Откройте http://localhost:8000. Правки видны сразу. Для другого языка добавьте в конец `-f mkdocs.uk.yml` или `-f mkdocs.en.yml`.

## Собрать сайт целиком

```bash
docker build -t a-faction-docs .
docker run --rm -p 3007:3007 a-faction-docs
```

Откройте http://localhost:3007. Сборка останавливается на любой битой ссылке или якоре, поэтому если она прошла — ссылки в порядке. Порт меняется переменной `PORT`.

## Как предложить правку

1. Исправьте статью во **всех трёх** языковых папках. Имя файла во всех языках одинаковое — на этом держится переключатель языка.
2. Новой статье нужна строка в разделе `nav` всех трёх файлов `mkdocs*.yml`.
3. Проверьте результат у себя и откройте pull request.

### Как пишутся статьи

- Для обычных людей: без технических слов и без обращений к разработчикам.
- У всех статей одинаковое устройство: короткое вступление, блок «Коротко» (где найти, кому доступно), шаги и таблица «Если не работает»: что видите, почему, что сделать.
- Сообщения об ошибках приводятся дословно, как их показывает панель. Discord-бот отвечает только по-русски, поэтому в английских и украинских статьях его сообщения даны в оригинале с переводом в скобках.
- Время панели указывается как UTC+3.
